## 2. 目标与非目标

### 2.1 目标

- **G1 左右丝滑切换**：首页（学习）与“我的”之间可以左右滑动切换，点击底部导航时带滑动动画，tab 高亮与页面位置双向同步。
- **G2 “我的”页卡片化**：资料卡 + 分组卡片（两列按钮网格），支持插件动态入口，视觉参照 BiliLite 的 `ProfileScreen`。
- **G3 主题变量**：浅色/深色/跟随系统；所有界面颜色、圆角由 CSS 变量驱动；主题切换即时生效并持久化。
- **G4 主题插件**：支持以 JSON 插件包写入颜色 token、圆角、背景图；支持插件注册“我的”页入口；主题管理器页面可以启用/恢复主题。

### 2.2 非目标（本阶段不做）

- 不改后端接口、数据库、检索/生成逻辑。
- 不重做首页聊天布局（只做外壳包裹与颜色 token 替换）。
- 不实现远程插件市场、下载安装、签名校验（只做本地/内置 JSON 插件）。
- 不实现 iOS/Android 原生插件（uni-app 插件只指前端 JSON/JS 模块）。

## 3. 总体方案

### 3.1 核心思路

**不再使用两个 tab 页面。** 把 `pages/index/index.vue` 改造成唯一的“宿主页”：

```
┌─────────────────────────────────────┐
│  宿主页 pages/index/index.vue        │
│  ┌───────────────────────────────┐   │
│  │ <swiper>                      │   │
│  │  item 0: 原首页聊天界面        │   │
│  │  item 1: <MyView />           │   │
│  └───────────────────────────────┘   │
│  <AppTabBar />（纯 UI，发事件）       │
└─────────────────────────────────────┘
```

- 首页代码**不搬出 index.vue**，避免 `onLoad/onShow/onHide/onUnload` 失效。
- “我的”页从 `pages/my/my.vue` 迁移为 `components/my/MyView.vue`（组件，不需要页面生命周期）。
- 删除 `pages.json` 的 `tabBar`；`uni.switchTab` 全部改为 `uni.reLaunch`。
- `AppTabBar` 只负责高亮和 `emit('change')`，真正切页由宿主页控制 swiper 的 `current`。

## 4. 设计规范（必须先落地 token，再做界面）

### 4.1 语义色 token

所有页面只允许使用以下 CSS 变量，不允许直接写颜色值。

| token | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `--ik-bg` | 页面背景 | `#f5f6f8` | `#14161a` |
| `--ik-card` | 卡片/输入底 | `#ffffff` | `#1e2126` |
| `--ik-t1` | 主文字 | `#1f2937` | `#e8eaed` |
| `--ik-t2` | 次文字 | `#4b5563` | `#aab1ba` |
| `--ik-t3` | 辅助文字/占位 | `#8a8f99` | `#8b929b` |
| `--ik-line` | 分割线/描边 | `#e5e7eb` | `#33373d` |
| `--ik-primary` | 主色/强调 | `#2b6cb0` | `#5b9bd5` |
| `--ik-primary-weak` | 主色浅底 | `#e8f0fb` | `#1f2d3d` |
| `--ik-on-primary` | 主色上的文字 | `#ffffff` | `#0b1220` |
| `--ik-block` | 关键操作/近黑块 | `#1f2937` | `#e8eaed` |
| `--ik-on-block` | 块上文字 | `#ffffff` | `#14161a` |
| `--ik-soft` | 次级容器 | `#f0f2f5` | `#262a30` |
| `--ik-input-bg` | 输入框底 | `#ffffff` | `#22262c` |
| `--ik-danger` | 错误 | `#e53e3e` | `#ff6b6b` |
| `--ik-success` | 正确/完成 | `#2f9e68` | `#4ade80` |
| `--ik-radius` | 全局圆角 | `24rpx` | `24rpx`（插件可覆盖） |

> 说明：`rpx` 是 uni-app 响应式单位，设计稿按 750 宽。BiliLite 的 `radius` 单位是 dp，若移植主题，**dp × 2 = rpx**。

### 4.2 尺寸与字阶

| 项 | 值 |
|---|---|
| 页面左右内边距 | `32rpx` |
| 卡片内边距 | `28rpx` |
| 卡片间距 | `24rpx` |
| 卡片圆角 | `var(--ik-radius)` |
| 头像 | `128rpx` 圆形 |
| 主标题 | `36rpx / 700` |
| 组标题 | `24rpx / 600`，颜色 `--ik-t2` |
| 按钮文字 | `26rpx` |
| 按钮高度 | `76rpx` |
| 两列间距 | `16rpx` |
| 底部导航高度 | `56px + env(safe-area-inset-bottom)`（沿用现有 wot 配置） |

### 4.3 卡片视觉

- 背景：`var(--ik-card)`
- 圆角：`var(--ik-radius)`
- 阴影：仅浅色模式 `0 8rpx 28rpx rgba(0,0,0,.06)`；深色模式改为 `0 0 0 1rpx var(--ik-line)`，避免黑底黑阴影。
- 分组按钮：`1rpx solid var(--ik-line)` 描边、透明背景、`var(--ik-t1)` 文字；禁用态 `opacity: .5`。
- 资料卡：头像在左、文字在右、操作按钮在最右（登录前为“登录”，登录后为“编辑”）。

### 4.4 深色模式

- 默认 `mode: 'system'`，读取系统主题；用户可强制 `light` / `dark`。
- 深色切换只改 CSS 变量，不重建页面。
- 原生导航栏页面（auth/history/path/profile）在 `onShow` 调 `uni.setNavigationBarColor` 跟随主色。

```js
// 底部导航集中配置：两项（“我的”不再是独立页面，仅作为 tab 标识）
export const TAB_INDEX = 'pages/index/index'
export const TAB_MY = 'pages/my/my' // 逻辑标识，不再对应真实路由

export const TAB_ITEMS = [
  { path: TAB_INDEX, title: '学习', icon: 'book' },
  { path: TAB_MY, title: '我的', icon: 'user' },
]

export function tabIndexByPath(path) {
  const i = TAB_ITEMS.findIndex((item) => item.path === path)
  return i < 0 ? 0 : i
}

export function tabPathByIndex(index) {
  return (TAB_ITEMS[index] || TAB_ITEMS[0]).path
}

/** 从外部页面回到宿主页的指定 tab（替代 uni.switchTab） */
export function requestTab(index = 0) {
  uni.reLaunch({ url: `/pages/index/index?tab=${index}` })
}

/** 原生 tabBar 已删除，保留空实现以防旧页面调用 */
export function hideNativeTabBar() {}
```

### 5.3 修改 `app/src/components/AppTabBar.vue`

把“导航”改成“发事件”：

```vue
<template>
  <view class="app-tabbar-wrap">
    <wd-tabbar
      :model-value="active"
      fixed
      placeholder
      safe-area-inset-bottom
      :z-index="100"
      :active-color="activeColor"
      :inactive-color="inactiveColor"
      :custom-style="tabbarStyle"
      @change="handleChange"
    >
      <wd-tabbar-item
        v-for="item in TAB_ITEMS"
        :key="item.path"
        :name="item.path"
        :title="item.title"
        :icon="item.icon"
      />
    </wd-tabbar>
  </view>
</template>

<script setup>
import { computed } from 'vue'
import { TAB_ITEMS } from '../tabbar.js'
import { tokens } from '../theme/theme.js'

const props = defineProps({
  active: { type: String, required: true },
})
const emit = defineEmits(['change'])

const activeColor = computed(() => tokens.value.primary)
const inactiveColor = computed(() => tokens.value.t3)
const tabbarStyle = computed(() =>
  `left: 0; right: 0; bottom: 0; transform: none; width: 100%; max-width: none;` +
  `border-radius: 0; background: ${tokens.value.card}; box-shadow: none;` +
  `--wot-tabbar-height: 56px; --wot-tabbar-item-icon-size: 26px;` +
  `--wot-tabbar-item-title-font-size: 11px;`
)

function handleChange({ value }) {
  if (!value || value === props.active) return
  emit('change', value)
}
</script>

<style>
.app-tabbar-wrap {
  flex: 0 0 auto;
  height: calc(64px + env(safe-area-inset-bottom));
}
</style>
```

#### 5.4.4 “丝滑”的关键参数

- `:duration="280"` + `easing-function="easeOutCubic"`：接近 Material 的标准曲线。
- **不要**给 `swiper` 加 `v-if`，两个 item 必须常驻，否则滑动时首帧重建会卡。
- 不要设置 `indicator-dots`。
- 手势冲突处理：
  - `Sidebar` 打开时 `:disable-touch="showSidebar"`，避免抽屉上的滑动误触发切页。
  - 首页 `scroll-view.chat` 是纵向滚动，uni-app 的 swiper 会自动区分横向/纵向手势，无需额外处理。
  - App 端若与系统侧滑返回冲突，在 `pages.json` 的 index 页面 `app-plus` 中加入：

### 7.2 新建 `app/src/theme/theme.js`

```js
import { reactive, computed, watch } from 'vue'
import { TOKENS, LIGHT, DARK } from './tokens.js'

const STORAGE_KEY = 'ikgr_theme_v1'

function readSaved() {
  try {
    const raw = uni.getStorageSync(STORAGE_KEY)
    return raw && typeof raw === 'object' ? raw : null
  } catch (e) {
    return null
  }
}

const saved = readSaved()

/**
 * 主题状态：
 * - mode: 'light' | 'dark' | 'system'
 * - pluginId: 当前启用的主题插件 id（空 = 默认）
 * - light / dark: 插件写入的 token 覆盖（优先于默认）
 * - lightRadius / darkRadius: 圆角覆盖，单位 rpx
 * - lightBg / darkBg: 背景图 URL
 */
export const themeState = reactive({
  mode: saved?.mode || 'system',
  systemDark: false,
  pluginId: saved?.pluginId || '',
  light: saved?.light || {},
  dark: saved?.dark || {},
  lightRadius: saved?.lightRadius ?? null,
  darkRadius: saved?.darkRadius ?? null,
  lightBg: saved?.lightBg || '',
  darkBg: saved?.darkBg || '',
})

export const isDark = computed(() =>
  themeState.mode === 'dark' ||
  (themeState.mode === 'system' && themeState.systemDark)
)

export const tokens = computed(() => ({
  ...(isDark.value ? DARK : LIGHT),
  ...(isDark.value ? themeState.dark : themeState.light),
}))

export const radius = computed(() => {
  const value = isDark.value
    ? (themeState.darkRadius ?? themeState.lightRadius ?? 24)
    : (themeState.lightRadius ?? 24)
  return value
})

export const backgroundImage = computed(() =>
  isDark.value
    ? (themeState.darkBg || themeState.lightBg)
    : themeState.lightBg
)

export const themeVars = computed(() => {
  const vars = {}
  for (const key of TOKENS) {
    vars[`--ik-${key}`] = tokens.value[key] || ''
  }
  vars['--ik-radius'] = `${radius.value}rpx`
  return vars
})

export function saveTheme() {
  try {
    uni.setStorageSync(STORAGE_KEY, {
      mode: themeState.mode,
      pluginId: themeState.pluginId,
      light: themeState.light,
      dark: themeState.dark,
      lightRadius: themeState.lightRadius,
      darkRadius: themeState.darkRadius,
      lightBg: themeState.lightBg,
      darkBg: themeState.darkBg,
    })
  } catch (e) {}
}

export function setMode(mode) {
  if (!['light', 'dark', 'system'].includes(mode)) return
  themeState.mode = mode
  saveTheme()
}

export function toggleDark() {
  setMode(isDark.value ? 'light' : 'dark')
}

export function initSystemTheme() {
  try {
    const info = uni.getSystemInfoSync()
    themeState.systemDark = info.theme === 'dark'
  } catch (e) {}
  try {
    if (typeof uni.onThemeChange === 'function') {
      uni.onThemeChange((res) => {
        themeState.systemDark = res.theme === 'dark'
      })
    }
  } catch (e) {}
}

// ---------- 插件主题 ----------

function pickTokens(source) {
  const out = {}
  if (!source || typeof source !== 'object') return out
  for (const key of TOKENS) {
    const value = source[key]
    if (typeof value === 'string' && /^#([0-9a-fA-F]{6}|[0-9a-fA-F]{8})$/.test(value.trim())) {
      out[key] = value.trim()
    }
  }
  return out
}

/**
 * 应用主题插件 manifest。
 * 兼容两种写法：
 * 1) 推荐：theme.colors / theme.darkColors
 * 2) 兼容 BiliLite：theme 顶层直接写 token（如 theme.bg）
 */
export function applyThemeManifest(manifest) {
  if (!manifest || manifest.type !== 'theme') return false
  const theme = manifest.theme || {}

  const lightSource = theme.colors || theme
  const darkSource = theme.darkColors || theme.dark || {}
  const light = pickTokens(lightSource)
  const dark = pickTokens(darkSource)

  if (!Object.keys(light).length && !Object.keys(dark).length) return false

  const radiusValue =
    typeof theme.radius === 'number' && theme.radius >= 0 ? theme.radius : null
  const darkRadiusValue =
    typeof theme.darkRadius === 'number' && theme.darkRadius >= 0
      ? theme.darkRadius
      : radiusValue

  Object.assign(themeState, {
    pluginId: manifest.id || '',
    light,
    dark,
    lightRadius: radiusValue,
    darkRadius: darkRadiusValue,
    lightBg: typeof theme.backgroundImage === 'string' ? theme.backgroundImage : '',
    darkBg: typeof theme.backgroundImageDark === 'string'
      ? theme.backgroundImageDark
      : (typeof theme.backgroundImage === 'string' ? theme.backgroundImage : ''),
  })
  saveTheme()
  return true
}

/** 恢复默认主题（保留用户选择的深浅模式） */
export function clearPluginTheme() {
  Object.assign(themeState, {
    pluginId: '',
    light: {},
    dark: {},
    lightRadius: null,
    darkRadius: null,
    lightBg: '',
    darkBg: '',
  })
  saveTheme()
}

/** 原生导航栏跟随主题主色（auth/history/path 等非自定义导航页用） */
export function applyNativeNavigationBar() {
  try {
    uni.setNavigationBarColor({
      // 深色模式下 primary 是浅蓝，用黑字；浅色模式下 primary 是深蓝，用白字
      frontColor: isDark.value ? '#000000' : '#ffffff',
      backgroundColor: tokens.value.primary,
    })
  } catch (e) {}
}

/**
 * 初始化：H5 把变量挂到 documentElement，保证 wot-ui 的
 * toast/dialog 等挂到 body 的组件也能取到变量。
 * App/小程序端由每个页面根节点 :style="themeVars" 提供。
 */
export function initThemeBridge() {
  initSystemTheme()
  // #ifdef H5
  watch(themeVars, (vars) => {
    const root = document.documentElement
    Object.entries(vars).forEach(([key, value]) => {
      if (value) root.style.setProperty(key, value)
    })
    root.setAttribute('data-theme', isDark.value ? 'dark' : 'light')
  }, { immediate: true })
  // #endif
}
```

>

### 8.2 新建 `app/src/themes/index.js`（扫描内置主题）

```js
import { TOKENS } from '../theme/tokens.js'

// Vite 在构建期扫描 JSON，新增主题目录后重启 dev server 即可
const modules = import.meta.glob('./*/theme.json', { eager: true })

function normalizeTheme(mod, path) {
  const manifest = mod.default || mod
  const theme = manifest.theme || {}
  const colors = { ...(theme.colors || {}) }
  const darkColors = { ...(theme.darkColors || theme.dark || {}) }

  // 兼容 BiliLite 平铺写法：theme 顶层直接写 bg/card/t1/...
  if (!Object.keys(colors).length) {
    for (const key of TOKENS) {
      if (typeof theme[key] === 'string') colors[key] = theme[key]
    }
  }

  return {
    ...manifest,
    __path: path,
    theme: { ...theme, colors, darkColors },
  }
}

export const BUILTIN_THEMES = Object.entries(modules)
  .map(([path, mod]) => normalizeTheme(mod, path))
  .filter((m) => m && m.type === 'theme' && m.id)
  .sort((a, b) => String(a.name).localeCompare(String(b.name), 'zh-Hans-CN'))

export function findTheme(id) {
  return BUILTIN_THEMES.find((m) => m.id === id) || null
}
```

> 主题背景图放在 `src/static/themes/...`，构建后路径为 `/static/themes/...`。不要用相对路径，否则 App 端可能解析失败。

### 8.3 新建 `app/src/plugin/menus.js`（插件入口注册表）

```js
import { reactive } from 'vue'

/** 供“我的”页渲染的插件入口 */
export const pluginMenus = reactive([])

export function registerMenu(menu) {
  if (!menu || !menu.id || !menu.label) return
  const item = {
    id: String(menu.id),
    label: String(menu.label),
    pluginId: menu.pluginId || '',
    handler: typeof menu.handler === 'function' ? menu.handler : null,
  }
  const index = pluginMenus.findIndex((m) => m.id === item.id)
  if (index >= 0) pluginMenus.splice(index, 1, item)
  else pluginMenus.push(item)
}

export function unregisterMenu(id) {
  const index = pluginMenus.findIndex((m) => m.id === id)
  if (index >= 0) pluginMenus.splice(index, 1)
}

export function runPluginMenu(menu) {
  try {
    if (menu && typeof menu.handler === 'function') menu.handler()
  } catch (e) {
    console.error('[plugin menu]', e)
    uni.showToast({ title: '插件执行失败', icon: 'none' })
  }
}

export function clearPluginMenus(pluginId) {
  for (let i = pluginMenus.length - 1; i >= 0; i -= 1) {
    if (pluginMenus[i].pluginId === pluginId) pluginMenus.splice(i, 1)
  }
}
```

### 8.4 新建 `app/src/plugin/runtime.js`（插件 API）

```js
import { applyThemeManifest, clearPluginTheme } from '../theme/theme.js'
import { registerMenu, unregisterMenu } from './menus.js'

/**
 * 创建插件 API。插件是“静态 JS 模块 + manifest”，不使用 eval。
 * 典型用法（app/src/plugins/index.js）：
 *
 *   import * as demo from './com.example.demo/index.js'
 *   const api = createPluginApi(demo.manifest)
 *   demo.activate?.(api)
 */
export function createPluginApi(manifest = {}) {
  return {
    manifest,
    ui: {
      /** 写入主题：theme 的格式与 theme.json 的 theme 字段一致 */
      setTheme(theme, options = {}) {
        return applyThemeManifest({
          id: options.id || manifest.id || '',
          name: options.name || manifest.name || '',
          type: 'theme',
          theme,
        })
      },
      resetTheme() {
        clearPluginTheme()
      },
      registerMenu(menu) {
        registerMenu({ ...menu, pluginId: manifest.id || '' })
      },
      unregisterMenu(id) {
        unregisterMenu(id)
      },
      toast(title) {
        uni.showToast({ title: String(title || ''), icon: 'none' })
      },
    },
  }
}
```

### 8.7 插件主题的优先级与持久化

优先级从高到低：

1. 当前启用的主题插件 `theme.colors` / `theme.darkColors`
2. 用户选择的浅/深模式默认 token（`LIGHT` / `DARK`）
3. `App.vue` 中 `page { --ik-* }` 的首帧兜底

持久化键：`ikgr_theme_v1`（`mode`、`pluginId`、`light`、`dark`、`radius`、`backgroundImage`）。冷启动时 `readSaved()` 同步读取，`initThemeBridge()` 在首屏前执行，避免闪白。

### 8.8 平台与安全限制

- **H5**：`import.meta.glob` 内置主题可用；`documentElement` 挂变量可覆盖挂到 `body` 的 wot-ui 弹层。
- **App（vue 页面）**：CSS 变量可用；`nvue` 页面**不支持 CSS 变量**，不要把主题页/我的页改成 nvue。
- **微信小程序**：不支持动态执行 JS；因此插件只能是 JSON 声明或打包时静态引入的 JS 模块。
- 不要把远程 URL 当作 `theme.json` 直接 `eval`；如需远程主题，必须 `fetch` 后 `JSON.parse`，并只接受白名单 token。
- 插件声明的 `permissions` 目前只是文档约定，前端不做强制；不要据此认为插件是安全的。

## 11. 风险与回滚

| 风险 | 表现 | 应对 |
|---|---|---|
| swiper 高度为 0 | 页面空白 | 确认 `.tab-swiper { flex:1; height:0 }` 且父级有确定高度 |
| 竖向滚动冲突 | 聊天列表滑不动 | 确认 `swiper` 未设置 `vertical`；`scroll-view` 有 `height:100%` |
| 两个 item 重建 | 滑动卡顿 | 不要用 `v-if`；不要把 MyView 放到 `v-show` 外 |
| 原生导航栏不跟主题 | 深色下蓝条突兀 | 每页 `onShow` 调 `applyNativeNavigationBar()` |
| wot 弹层不跟主题 | toast/dialog 仍是默认色 | H5 在 `documentElement` 挂变量；App 端将 `theme-root` 类加到弹层容器或改用 `wd-config-provider` |
| 旧页面 `switchTab` 残留 | 点击无反应/报错 | 全局搜索 `switchTab`，按 5.5 全部替换 |
| 插件颜色非法 | 页面变透明/黑块 | `pickTokens` 已做正则校验；补 `try/catch` |
| 改坏首页 | 无法问答 | 阶段 3 只包外壳，不改业务；保留 git 分支，按阶段回滚 |

**回滚策略**：

- 阶段 1-2 的改动集中在 `pages.json`、`tabbar.js`、`AppTabBar.vue`、`index.vue` 模板、`my.vue`。回滚这几个文件即可恢复原生 tabBar。
- 阶段 3-4 是纯新增文件；删除 `theme/`、`plugin/`、`themes/`、`pages/theme/` 并还原 `App.vue` 即可。
