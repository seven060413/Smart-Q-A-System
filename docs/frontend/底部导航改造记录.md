# 底部导航改造记录

> 结果：原生 tabBar 已替换为 **Wot UI 悬浮胶囊导航**，原生配置保留但运行时隐藏。
> 本文保留最终做法、关键决策和扩展方式；逐步调试过程已压缩。
> 相关文件：[`AppTabBar.vue`](../../app/src/components/AppTabBar.vue)、
> [`tabbar.js`](../../app/src/tabbar.js)、[`pages.json`](../../app/src/pages.json)、
> [`App.vue`](../../app/src/App.vue)、[`index.vue`](../../app/src/pages/index/index.vue)、
> [`my.vue`](../../app/src/pages/my/my.vue)。

## 1. 最终结果

- 首页和“我的”页显示 Wot UI 悬浮胶囊导航（学习 / 我的）。
- 原生 tabBar 仍保留在 `pages.json`，保证 `uni.switchTab` 可用，但显示被隐藏。
- 历史、学习路径、登录/账号页不显示底部导航。
- 输入栏顺序为“输入框 → 语音 → 发送”，导航不遮挡输入栏；语音图标旋转 90°。

## 2. 关键决策

| 决策 | 原因 |
|---|---|
| 引入 `@wot-ui/ui@2.4.0` + `sass@^1.98.0` | 项目原本没有 UI 库；只为导航引入，不迁移其他页面 |
| 保留原生 tabBar，用 `uni.hideTabBar()` 隐藏 | `switchTab` 只接受 `tabBar.list` 页面；`custom: true` 不支持 App/H5 |
| 导航使用受控 `:model-value="active"` | 避免隐藏页面保留旧选中值，切回时高亮错误 |
| 外层固定预留 64px + 安全区 | `placeholder` 挂载后才测量，首帧可能为 0，导致输入栏跳动 |
| H5 用 CSS 立即隐藏原生 tabBar | 避免首帧闪出；App 端原生 tabBar 不是 DOM，只能调用 `uni.hideTabBar` |

## 3. 代码结构

[`tabbar.js`](../../app/src/tabbar.js) 集中管理路径、标题、图标：

```js
export const TAB_INDEX = 'pages/index/index'
export const TAB_MY = 'pages/my/my'
export const TAB_ITEMS = [
  { path: TAB_INDEX, title: '学习', icon: 'book' },
  { path: TAB_MY, title: '我的', icon: 'user' },
]
```

[`AppTabBar.vue`](../../app/src/components/AppTabBar.vue) 使用受控 tabbar：

```vue
<wd-tabbar :model-value="active" fixed placeholder safe-area-inset-bottom
  shape="round" :z-index="100" active-color="#2b6cb0" inactive-color="#8a8f99"
  custom-style="..." @change="handleChange">
  <wd-tabbar-item v-for="item in TAB_ITEMS" :key="item.path"
    :name="item.path" :title="item.title" :icon="item.icon" />
</wd-tabbar>
```

页面传入自己的路径：首页 `:active="TAB_INDEX"`，我的 `:active="TAB_MY"`。

隐藏原生 tabBar：

| 位置 | 调用 |
|---|---|
| `App.vue` | `onLaunch`、`onShow` 调用 `hideNativeTabBar()` |
| `index.vue` / `my.vue` | `onLoad`、`onShow` 调用 |
| `App.vue` H5 样式 | `uni-tabbar { display: none !important; }` |

## 4. 悬浮胶囊关键样式

```text
left: 50%; right: auto;
bottom: calc(8px + env(safe-area-inset-bottom));
transform: translateX(-50%);
width: calc(100% - 48px); max-width: 420px;
border-radius: 28px; background: #fff;
box-shadow: 0 6px 20px rgba(43, 108, 176, 0.14);
--wot-tabbar-height: 56px;
--wot-tabbar-item-icon-size: 26px;
```

外层 `.app-tabbar-wrap` 固定 `height: calc(64px + env(safe-area-inset-bottom))`，
64px = 56px 胶囊 + 8px 间距，消除首帧跳动。

## 5. 已修复的问题

| 问题 | 修复 |
|---|---|
| 切换 tab 后高亮错误 | 从 `v-model` 改为受控 `:model-value="active"`，高亮永远等于当前路由 |
| 首帧输入栏跳动 | 外层固定预留 64px + 安全区 |
| 原生 tabBar 闪烁 | H5 用 CSS 立即隐藏；App 多个生命周期调用 `uni.hideTabBar` |
| 截图右侧被裁 | 用 CDP 强制 390×844、320×568 重新测量，确认无横向溢出 |
| Sass `legacy-js-api` 警告 | 不影响构建，保留 |

## 6. 扩展到 3–4 项

新增页面（例如“练习”）需要改四处：

1. 新建 `app/src/pages/practice/practice.vue`；
2. `pages.json` 的 `pages` 注册路由；
3. `pages.json` 的 `tabBar.list` 加入 `pagePath`（原生仍隐藏，只为 `switchTab`）；
4. `tabbar.js` 增加 `TAB_PRACTICE` 和 `TAB_ITEMS` 项。

```js
export const TAB_PRACTICE = 'pages/practice/practice'
export const TAB_ITEMS = [
  { path: TAB_INDEX, title: '学习', icon: 'book' },
  { path: TAB_PRACTICE, title: '练习', icon: 'edit' },
  { path: TAB_MY, title: '我的', icon: 'user' },
]
```

`wd-tabbar-item` 本身 `flex: 1`，增加项会自动均分。历史、学习路径、登录/账号页
不要加入 `TAB_ITEMS` 或 `tabBar.list`。

> 三处路径必须一致：`pages.json` 的 `pages[].path`、`tabBar.list[].pagePath`、
> `tabbar.js` 常量。图标名必须在
> `app/node_modules/@wot-ui/ui/components/wd-icon/iconfont.scss` 中。
