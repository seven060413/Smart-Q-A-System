> 把问答的**知识点匹配范围**从“五年级下册子图”扩展到“全量数学图谱”，
> 同时评估并调整拒答阈值、提示词、前置诊断、出处溯源和持久化元数据。
>
> 评估脚本：[scripts/evaluate_qa_scope.py](../../scripts/evaluate_qa_scope.py)
>
> 相关代码：[src/api.py](../../src/api.py)、[src/settings.py](../../src/settings.py)、
> [src/linking.py](../../src/linking.py)、[src/refusal.py](../../src/refusal.py)、
> [src/pipeline.py](../../src/pipeline.py)、[src/diagnosis.py](../../src/diagnosis.py)。

| 项 | 改造前 |
| --- | --- |
| 匹配候选 | `data/processed/math_5b_knowledge_graph.json` |
| 候选节点 | 67 个（45 Concept + 14 Skill + 8 Chapter） |

## 2. 最终方案

| 项 | 改造后 |
| --- | --- |
| 匹配候选（默认） | `data/raw/math.json` 全量知识图谱 |
| 候选节点 | 2711 个节点，其中 **1898 个** Concept/Skill |
| 教材册数 | 23 本 |
| 匹配算法 | 仍为字符 Dice + 覆盖度，增加短别名/英文别名过滤和精确命中兜底 |
| 拒答阈值（默认） | **0.35** |
| 出处 | 沿 `appears_in → is_part_of` 动态找到实际教材与章节 |
| 回滚方式 | `QA_MATCH_SCOPE=book_5b` |
| 新增依赖 | 无 |

核心配置：

```ini
# .env
QA_MATCH_SCOPE=full
# 可选，默认 0.35
# QA_LINK_THRESHOLD=0.35
```

`api.py` 启动时按 scope 加载候选：

```python
match_scope = qa_match_scope()

```

启动日志会打印：

```text
qa match scope=full candidates=1898
```

修改 `.env` 后必须重启后端。

## 3. 匹配逻辑的调整

### 3.1 为什么要调整

直接把 59 个候选换成 1898 个后，原来的“覆盖率”权重会带来新的误匹配：

- 24 个知识点名只有 1 个字（比、时、分、圆、球……）；
- 部分别名也很短（如「直方图」的别名「图」）；
- 部分别名是英文（plane、slope、angle），会把 apple、Photoshop 里的片段算进去。

实测原始评分下，50 条数学域外问题最高分 **0.333**，如果阈值仍是 0.2，
会接受「英语单词 apple 怎么读」「足球比赛规则是什么」等问题。

### 3.2 过滤规则

在 [src/linking.py](../../src/linking.py) 中增加：

1. **单字候选不参与模糊打分**  
   只在明确问法下命中：`什么是 X`、`X 是什么`、`X 表示什么`、`X 的含义`、`X 的意思`。
2. **纯英文候选必须是完整单词**  
   使用单词边界匹配，避免 `plane` 命中 `apple`、`slope` 命中 `Photoshop`。
3. 其余候选仍按 `0.7 × Dice + 0.3 × 覆盖率` 打分。

### 3.3 精确命中兜底

当模糊最高分低于阈值时，[src/refusal.py](../../src/refusal.py) 的 `link_top` 会再找一次
问句中明确出现的知识点名/别名：

- 中文候选长度 ≥ 2：直接子串匹配；
- 单字候选：只接受上述明确问法；
- 英文候选：完整单词匹配；
- 多个候选同时命中时，优先更长的名称（`真分数` 优于 `分数`）。

精确命中时返回 `max(模糊分, 阈值)`，表示“已覆盖”，避免短名合法问题被拒答。

示例：

| 问句 | 结果 |
| --- | --- |
| 什么是比 | 精确兜底命中「比」，接受 |
| 足球比赛规则是什么 | 只是碰巧包含「比」，不构成问法，拒答 |
| 什么是真分数 | 命中「真分数」，不会退化成「分数」 |

## 4. 拒答阈值评估

评估脚本：

```powershell
cd D:\IKGR-system-eands
.venv/Scripts/python.exe scripts/evaluate_qa_scope.py --scope full
```

### 4.1 数据集

| 集合 | 内容 |
| --- | --- |
| 正例 A | 1898 条「什么是{知识点名}」 |
| 正例 B | 12 条自然数学问题（分数、方程、函数、概率等） |
| 负例 | 50 条数学域外问题（生活、英语、历史、电脑等） |

### 4.2 评估结果

改造后（已加过滤规则）：

| 阈值 | 域外问题被误接受 | 自然数学问题被接受 |
| --- | --- | --- |
| 0.20 | 4 / 50 | 12 / 12 |
| 0.25 | 2 / 50 | 12 / 12 |
| 0.30 | 0 / 50 | 12 / 12 |
| **0.35** | **0 / 50** | **12 / 12** |
| 0.40 | 0 / 50 | 12 / 12 |
| 0.45 | 0 / 50 | 12 / 12 |

其他数据：

- 50 条域外问题最高模糊分：**0.288**；
- 12 条自然数学问题最低模糊分：**0.46**；
- 1898 条名称问句 Top-1 同名/同 id：**1873 / 1898 = 98.7%**；
- 其中 24 条模糊分 < 0.2，正好是 24 个单字知识点名，由精确问法兜底。

### 4.3 选择 0.35 的理由

- 高于域外样本最高分 0.288，留出约 0.06 余量；
- 低于自然问题最低分 0.46；
- 单字知识点不会因为阈值提高而丢失（精确兜底）；
- 阈值仍可通过 `QA_LINK_THRESHOLD` 调整，不需要改代码。

### 4.4 过滤前后的典型误匹配

| 问题 | 过滤前最高分 | 过滤后最高分 | 处理 |
| --- | --- | --- | --- |
| 英语单词 apple 怎么读 | 0.333（平面/plane） | 0.100（单位1） | 拒答 |
| 足球比赛规则是什么 | 0.300（比、球） | 0.277（数独规则） | 拒答 |
| 苹果手机怎么截图 | 0.300（直方图/别名「图」） | 0.150（视图） | 拒答 |
| 秦始皇统一六国的时间 | 0.300（时） | 0.288（时间的估计） | 拒答 |

## 5. 前置诊断与学习路径评估

全量图谱下统计 1898 个知识点：

| 指标 | median | p90 | p99 | max |
| --- | --- | --- | --- | --- |
| 直接前置（必需） | 0 | 1 | 3 | 5 |
| 全部前置（含间接） | 0 | 2 | 5 | 14 |
| 巩固层 | 0 | 3 | 5 | 10 |

其他结论：

- 前置关系图共 853 条前置边，**是 DAG（无环）**；
- 因此不会因为扩展到全量图谱而触发 `build_learning_path` 的环检测报错；
- 前置/巩固列表规模很小，不需要截断，提示词不会因此变长到不可控；
- 原有的“人为插入环 → 报错”测试继续保留。

### 5.1 出处溯源修正

原实现硬编码：

```python
BOOK_CITATION = "人教版五年级下册"
```

扩展到全量后会给出错误出处。现改为沿：

```text
知识点 --appears_in--> 章节 --is_part_of--> 教材 Book
```

读取 `Book.properties.publisher / grade`，例如：

| 知识点 | 新出处 |
| --- | --- |
| 异分母分数加减法 | 人教版五年级下册·分数的加法和减法 |
| 比 | 人教版六年级上册·比、总复习 |
| 导数 | 人教版选择性必修二·第一节 导数的概念及其意义、第二节 导数的运算 |

高中教材的 publisher 原始值很长（含主编信息），输出时只取出版社主体（如「人教版」）。

### 5.2 持久化元数据

`graph_version_id` 原来固定记录五下 book 版本。全量匹配后：

- full 模式：`graph_version_id = subject_full`；
- `context_graph_version_id = subject_full`；
- book_5b 模式：`graph_version_id = 五下 book 版本`。

没有 full 版本时回退到 book 版本，避免历史库未导入全量图谱时写入空值。

## 6. 提示词调整

[src/pipeline.py](../../src/pipeline.py) 的 `build_prompt`：

- 「你是小学数学助教」→「你是**中小学**数学助教」；
- 「不得编造教材中没有的内容」→「不得编造**知识图谱**中没有的内容」；
- 证据仍然只来自图谱：本体名称+定义、必需/建议前置、巩固延伸、教材出处；
- 出处现在是实际教材，不再固定五年级下册；
- 输出格式改为「【讲解】+【巩固练习】」两段，见 6.1。

### 6.1 巩固练习独立生成

**问题**：原来的「巩固练习」卡片只读取图谱巩固层
`learning_path.consolidation`，并不是大模型生成的练习题。全量图谱里
**1014 / 1898（53.4%）** 的知识点巩固层为空，例如「真分数」只有
`appears_in` 边，没有后继或 `relates_to`，卡片只能显示「无」。
大模型回答里的第三段「巩固延伸」属于 `answer` 正文，不会被卡片使用。

**改造**：

1. 提示词要求模型严格输出：

   ```text
   【讲解】
   1. 先补前置：……
   2. 再讲本体：……

   【巩固练习】
   1. 题目：……；下一行「答案：……」。
   2. 题目：……；下一行「答案：……」。
   ```

2. [src/pipeline.py](../../src/pipeline.py) 新增
   `split_generated_answer(text)`：
   - 按「【巩固练习】/## 巩固练习」拆出练习段；
   - 按 `1. / 1、/ 1) / （1） / - / •` 拆分题目；
   - 没有标题时兼容旧格式，整段作为正文、练习为空；
   - 兼容 Markdown 标题和「【讲解】」标题。

3. [src/api.py](../../src/api.py) 的 `_fill_answer`：

   - `answer` 只保留讲解正文；
   - 新增顶层 `exercises: list[str]`；
   - 同时写入 `learning_path.exercises`，随
     `messages.learning_path_json` 持久化，历史消息可原样还原；
   - 不需要数据库迁移。

4. [src/chat_service.py](../../src/chat_service.py)：
   历史消息和幂等重放响应都会返回 `exercises`。

5. 前端 [app/src/pages/index/index.vue](../../app/src/pages/index/index.vue)：

   - 有 `exercises` 时逐题显示，题干和答案按换行展示；
   - 旧历史消息没有 `exercises` 时，回退显示图谱巩固层知识点；
   - 两者都没有时显示「暂无巩固练习」。

6. [src/generator.py](../../src/generator.py) 的 `max_tokens` 从 800
   提高到 1200，给讲解和两道练习留出空间。

前端首页欢迎语同步从「小学数学助教」改为「中小学数学助教」。

## 9. 已知限制

1. **仍是字面匹配，不是语义匹配**  
   例如「圆面积怎么算」会先匹配到「面积」，而不是「圆的面积」；
   同义表达、口语化问题可能低于阈值被拒答。
2. **9 个知识点名在不同教材中重复**（如「估算」「比较数量」）  
   字面分数相同，可能选到另一册的同名节点；当前没有按年级/教材二次排序。
3. **阈值是离线样本标定**  
   0.35 在 50 条域外问题和 12 条自然问题上是分离的，但不能保证覆盖所有说法。
4. **出处可能包含多本教材/多个章节**  
   一个知识点出现在多册时，出处会用「、」连接，文本较长。
5. **前面提到的语义检索没有接入**  
   `retrieval.py` 的 bge-m3 仍未进入 `/api/ask`；服务端最小依赖不含 torch/FlagEmbedding。
6. **高中内容进入回答范围**  
   产品文案已改为「中小学」，但界面/课程定位如果需要限定小学，应改用更细的 scope。

后续可做的增强：

- 用 BM25/字符 n-gram + 语义向量混合召回；
- 对同名知识点按当前年级/教材优先；
- 按学段限制候选（小学 / 初中 / 高中）；
- 收集线上真实问句，持续校准阈值。
