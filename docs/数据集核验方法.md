# K12-KGraph 数据集核验方法

目的：独立查证数据集来源、规模、类型、授权与版本，形成可复现的证据链（答辩可用）。

---

## 一、三个信息源，各查什么

| 信息源 | 地址 | 查什么 | 可信度 |
| --- | --- | --- | --- |
| **HuggingFace 仓库** | https://huggingface.co/datasets/lhpku20010120/K12-KGraph | 实际数据文件、schema 声明、更新时间、授权标签 | 最高（数据本体） |
| **GitHub 仓库** | https://github.com/haolpku/K12-Dataset | 团队、论文链接、构建流程、README 中的 schema | 高（官方说明） |
| **arXiv 论文** | https://arxiv.org/abs/2605.09635 | 理论设计、评测基准、作者与机构 | 高（学术来源，但可能是设计版） |

> **核心原则**：三者不一致时，**以实际下载数据的统计结果为准**。

## 三、手动核验步骤（不依赖脚本）

### 1. 确认「是不是最新版」

**方法 A：看仓库信息（推荐）**

浏览器打开：

```
https://huggingface.co/api/datasets/lhpku20010120/K12-KGraph
```

返回 JSON，重点看：

| 字段 | 含义 |
| --- | --- |
| `lastModified` | 最后更新时间 |
| `siblings` | 仓库内全部文件列表 |
| `cardData.license` | 授权协议 |
| `downloads` / `likes` | 使用热度（辅助判断影响力） |

**方法 B：看页面**

在数据集页面点 **Files and versions** → 右上角能看到最新 commit 的时间与哈希。

### 2. 下载原始文件并统计

**命令行下载**：

```bash
# 全局图谱
curl -L -o nodes.json "https://huggingface.co/datasets/lhpku20010120/K12-KGraph/resolve/main/K12-KGraph/global_KG/nodes.json"
curl -L -o edges.json "https://huggingface.co/datasets/lhpku20010120/K12-KGraph/resolve/main/K12-KGraph/global_KG/edges.json"

# 数学学科图谱
curl -L -o math.json "https://huggingface.co/datasets/lhpku20010120/K12-KGraph/resolve/main/K12-KGraph/subject_specific_KG/math.json"
```

**统计类型数量**（Python）：

```python
import json, collections

nodes = json.load(open("nodes.json", encoding="utf-8"))
edges = json.load(open("edges.json", encoding="utf-8"))

print("节点总数:", len(nodes))
print("边总数:", len(edges))
print("节点类型:", collections.Counter(n["label"] for n in nodes))
print("关系类型:", collections.Counter(e["type"] for e in edges))
```

**判断标准**：

- `Counter` 的**键的个数** = 类型数量
- 键的名称 = schema 中的类型名
- 与 HF 卡片、GitHub README 的描述逐项对照

### 3. 核对授权

- HuggingFace 页面顶部标签应显示 **CC BY-NC-SA 4.0**；
- API 返回的 `cardData.license` 应为 `cc-by-nc-sa-4.0`；
- GitHub 仓库根目录应有 `LICENSE`（数据集）与 `LICENSE-CODE`（代码，MIT）。
- **含义**：署名 + 非商业 + 相同方式共享 → 课程研究可用，不可商用。

### 4. 核对论文说法

打开 https://arxiv.org/abs/2605.09635 ，确认：

| 核对项 | 位置 |
| --- | --- |
| 标题 | 页面顶部 |
| 作者与机构 | 作者列表 / PDF 首页 |
| 节点与关系类型数 | 方法章节（Method / Schema） |
| 数据集构成（K12-Bench / K12-Train） | 实验章节 |
| NeurIPS 接收信息 | arXiv 页面**通常不写**，以 GitHub README 或会议官网为准 |

### 5. 核对学科与学段覆盖

从下载的数据里看节点 id 前缀，例如：

```
math_5b_rjb_cpt35      → 数学 · 五年级下册 · 人教版
physics_8a_rjb_cpt12   → 物理 · 八年级上册 · 人教版
chemistry_bx1_rjb_...  → 化学 · 必修一
biology_7a_rjb_...     → 生物 · 七年级上册
```

命令：

```python
import json, re, collections
nodes = json.load(open("nodes.json", encoding="utf-8"))
subject = collections.Counter(re.match(r"^([a-z]+)_", n["id"]).group(1) for n in nodes)
print(subject)
```

## 四、已核实结论（截至 2026-10-18）

| 说法 | 结论 | 依据 |
| --- | --- | --- |
| 北大 PKU-DCAI 团队构建 | ✅ 属实 | GitHub README |
| NeurIPS 2026 接收 | ✅ 属实（Evaluations & Datasets Track） | GitHub README |
| HuggingFace / GitHub 开源 | ✅ 属实 | 两个仓库均可访问并下载 |
| 覆盖人教社数理化生、小学到高中 | ✅ 属实 | 实测 48 册教材（数学 23、物理 9、化学 7、生物 9） |
| **9 种节点类型、14 种关系类型** | ❌ **与开源数据不符** | 论文写 9/14，**实际数据为 7 种节点、9 种关系** |
| K12-Bench / K12-Train | ✅ 属实 | Bench 23,640 题；Train 2,267 文本 QA（另有 5,068 多模态） |

**差异说明**：论文描述的是完整设计 schema（可能含视觉锚定等类型），
开源发布版本实际只包含 7 类节点与 9 类关系。引用时应以实际数据为准。

## 六、注意事项

1. **只引用能复现的数字**：凡是写进报告的数量，都应有脚本或命令能重新算出来；
2. **记录核验时间**：数据集会更新，注明「截至 YYYY-MM-DD」；
3. **区分「论文设计」与「开源发布」**：两者不一致时以数据为准，并说明差异；
4. **不要提交原始数据到 git**：`data/raw/` 已在 `.gitignore` 中忽略，仅保留 `data/README.md` 说明。
