# 真机调试与 APK 打包操作指南

> 本项目前端位于 `app/`（uni-app + Vue3），后端为 FastAPI。
> 本文只讲操作步骤。**参数请以你机器实际值为准**，下文出现的值是本机实测值。

---

## 0. 打包前必须先补两处（否则一定失败）

| 项 | 现状 | 要改成 |
| -- | -- | -- |
| `app/src/manifest.json` 的 `name` | 空 | 如 `数学知识问答` |
| `app/src/manifest.json` 的 `appid` | 空 | 在 HBuilderX 里「重新获取 appid」，形如 `__UNI__XXXXXXX` |
| `app/src/config.js` 的 `BASE_URL` | `127.0.0.1:18080` | 手机要访问电脑，必须改成局域网 IP，见第 4 节 |

**获取 appid 的方法**：HBuilderX 打开项目 → 双击 `manifest.json` → 左侧「基础配置」→ 点「重新获取 appid」（需登录 DCloud 账号，免费注册）。

---

## 1. 手机开启开发者模式 + USB 调试

以常见安卓机型为例（华为/小米/OPPO/vivo 大同小异）：

1. **打开「关于手机」**：设置 → 关于手机（部分机型在 设置 → 系统 → 关于手机）；
2. **连点版本号 7 次**：点击「版本号」（华为是「版本号」，小米是「MIUI 版本」），提示「您已处于开发者模式」；
3. **进入开发者选项**：设置 → 系统 → 开发者选项（小米在 设置 → 更多设置 → 开发者选项）；
4. **打开两个开关**：
   - `USB 调试` —— 必开；
   - `USB 安装`（有的叫「通过 USB 安装应用」「允许 USB 安装」）—— 必开，否则打包后装不上；
5. **插上 USB 线**，手机弹出「允许 USB 调试吗？」→ 勾选「一律允许」→ **确定**；
   - 若没弹窗：下拉通知栏，把 USB 用途从「仅充电」改成「**传输文件 / MTP**」，弹窗通常就出来了。

> 小米/红米额外注意：开发者选项里的「USB 调试（安全设置）」也建议打开，否则 HBuilderX 可能连不上。

---

## 2. HBuilderX 运行到 Android 真机

1. **导入项目**：HBuilderX → 文件 → 导入 → 从本地目录导入 → 选 `D:\IKGR-system-eands\app`；
   - ⚠️ 注意选的是 **app 目录**（里面有 `package.json`、`src/`），不是项目根目录；
2. **装依赖**（若没装过）：HBuilderX 内置终端里 `cd app` 后执行 `npm install`；
   - 若提示 `npm 不是命令`，见第 5 节「常见报错」；
3. **确认手机已连上**：HBuilderX 顶部菜单 → 运行 → 运行到手机或模拟器 → **运行到 Android App 基座**；
   - 若列表里没有你的手机，点「刷新」；
4. **首次运行会安装「HBuilder 标准基座」**到手机（约 30MB），耐心等提示「安装成功」；
5. 手机上自动打开 App，即可看到界面。**此时是真机调试模式**，改代码保存后会自动刷新。

> 真机调试时，手机访问后端走的是**局域网**，不是 `127.0.0.1`——务必先完成第 4 节配置。

---

## 3. 云打包生成 APK（DCloud 公共测试证书）

> 不上架应用商店，用官方**公共测试证书**即可，无需自建证书、无需花钱。

1. **确认配置已改好**：`manifest.json` 的 `name`、`appid` 已填，`config.js` 的 `BASE_URL` 指向电脑局域网 IP（第 4 节）；
2. HBuilderX → 顶部菜单 **发行 → 原生 App-云打包**；
3. 弹出打包对话框，按下表填写：

   | 选项 | 选择 |
   | -- | -- |
   | 平台 | ✅ Android（iOS 需苹果开发者账号，本项目不需要） |
   | 打包方式 | **使用 DCloud 老版证书** / **公共测试证书** |
   | 证书 | 选「**DCloud 公共测试证书**」（免费，仅测试用） |
   | 广告联盟 | 取消勾选（不需要） |
   | 打包渠道 | 默认即可 |

4. **包名（Android 包名）建议**：
   - 格式：`com.公司/组织名.应用名`，全小写、至少两段、不含中文和横线；
   - 本项目建议：**`com.ikgr.mathqa`**（或 `cn.edu.你的学校.ikgr`）；
   - ⚠️ 包名一旦用于正式发布不可更改，测试阶段可随意，但建议早点定好；
5. 点「打包」→ 等待云端编译（首次约 3–10 分钟，HBuilderX 底部会显示进度）；
6. **打包完成后 APK 在哪**：
   - HBuilderX 控制台会给出**下载链接**，点击即可下载；
   - 同时会发到你的 DCloud 账号邮箱；
   - 本地路径：`app/unpackage/release/apk/` 目录下（文件名形如 `__UNI__XXXX__20261017.apk`）。

### 传到手机安装

三种方式任选：

1. **USB 拷贝**（推荐）：手机连电脑 → 选「传输文件」→ 把 APK 拖到手机「下载」目录 → 手机上用「文件管理」找到它点击安装；
2. **微信/QQ 传**：电脑微信发给自己 → 手机微信打开 → 用「其他应用打开」安装；
3. **HBuilderX 直接安装**：手机连着 USB 时，在打包结果页点「**安装到手机**」。

> 安装时若提示「未知来源应用」→ 在弹窗里点「设置」→ 允许该来源安装即可。

## 4. 打包前检查清单（重点！）

### 4.1 App 里的后端地址是否正确

打开 [app/src/config.js](../app/src/config.js)，确认：

```js
export const BASE_URL = 'http://192.168.105.137:18080'
```

- **必须是电脑的局域网 IP**，不能是 `127.0.0.1` 或 `localhost`——那在手机上指的是手机自己；
- 本机实测：局域网 IP 是 **`192.168.105.137`**（WLAN 网卡）；
- **查 IP 的方法**：命令行执行 `ipconfig`，找「无线局域网适配器 WLAN」下的 **IPv4 地址**；
- ⚠️ **别选错网卡**！你机器上还有这些虚拟网卡，都不是：
  - `192.168.56.1`（VirtualBox Host-Only）
  - `192.168.239.1` / `192.168.47.1`（VMware VMnet8 / VMnet1）
  - `26.156.135.21`（Radmin VPN）

### 4.2 手机与电脑是否在同一 Wi-Fi

- 手机和电脑必须连**同一个 Wi-Fi**（同一个路由器）；
- 手机不要开 4G/5G 流量（会走移动网络，访问不到电脑）；
- **验证方法**：手机浏览器打开 `http://192.168.105.137:18080/`，若显示 `{"service":"中小学教材知识图谱智能问答系统",...}` 就说明通了。

### 4.3 后端必须监听 `0.0.0.0`（不是 127.0.0.1）

手机要能访问，后端不能只绑本机回环地址。**启动命令必须加 `--host 0.0.0.0`**：

```bash
cd D:\IKGR-system-eands
.venv\Scripts\python.exe -m uvicorn src.api:app --host 0.0.0.0 --port 18080
```

> 本项目本机 **8000 端口被系统占用**（实测绑定报 `Errno 13 权限不足`），故一直使用 **18080**。
> 若你坚持用 8000，需先排查占用：`netstat -ano | findstr :8000`。

### 4.4 电脑防火墙放行端口

首次用 `0.0.0.0` 启动时，Windows 会弹「是否允许 Python 访问网络」→ **勾选「专用网络」→ 允许**。

若当时点了「取消」，手动放行：

```powershell
# 以管理员身份打开 PowerShell，执行（放行 18080）
New-NetFirewallRule -DisplayName "IKGR Backend 18080" -Direction Inbound -Protocol TCP -LocalPort 18080 -Action Allow
```

若用的是 8000，把上面两条的 `18080` 改成 `8000`。

**外加检查**：有些杀毒软件（360、火绒）有自己的防火墙，需在其「网络防护」里放行 Python。

## 5. 常见报错排查

### 5.1 App 白屏

| 可能原因 | 排查方法 |
| -- | -- |
| JS 报错 | HBuilderX → 运行 → 运行到手机 → 打开「控制台」，看有无红色报错 |
| 页面路径写错 | 检查 `pages.json` 里注册的路径与实际文件是否一致 |
| 用了浏览器专有 API | 真机不支持 `window`/`document`，改用 `uni.*` 接口 |
| 基座版本不匹配 | 重新「运行到 Android App 基座」，让 HBuilderX 重装基座 |
| 云打包后白屏但真机运行正常 | 多半是 `BASE_URL` 没改或后端没起，见 5.2 |

### 5.2 请求失败 / 连不上后端

按**从近到远**的顺序排查：

1. **后端起了吗**：电脑浏览器打开 `http://127.0.0.1:18080/`，有 JSON 返回才算起了；
2. **监听地址对吗**：必须 `--host 0.0.0.0`，只写 `127.0.0.1` 手机连不上；
3. **防火墙放行了吗**：见 4.4；
4. **IP 对吗**：手机浏览器直接访问 `http://192.168.105.137:18080/`——通了说明网络层面没问题，问题在 App 的 `config.js`；
5. **同一 Wi-Fi 吗**：见 4.2；
6. **CORS**：后端已开启 CORS（`allow_origins=["*"]`），一般无需额外处理；
7. **改了 `config.js` 要重新打包**：H5 调试下改完刷新即可，**真机/APK 必须重新运行或重新打包**才生效。

### 5.3 打包证书 / 打包报错

| 报错 | 原因与解决 |
| -- | -- |
| `appid 不能为空` | `manifest.json` 的 `appid` 没填，在 HBuilderX 里「重新获取 appid」 |
| `包名格式不正确` | 包名必须是 `com.xxx.yyy` 形式，全小写、不含中文/横线 |
| `未登录 DCloud 账号` | HBuilderX 右上角登录（免费注册） |
| `证书已过期` / `证书错误` | 用「**DCloud 公共测试证书**」，不用自建证书 |
| 打包成功但装不上 | 手机没开「USB 安装」/「未知来源应用」权限，见第 1、3 节 |
| 打包卡在「正在编译」很久 | 云端排队，耐心等；超过 30 分钟去看 HBuilderX 消息中心的打包记录 |
| `名称长度不符合规范` | `manifest.json` 的 `name` 建议 2–12 个字符 |
