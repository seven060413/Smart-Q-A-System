从一次问答，到下一次回来

起点

答案结束之后，
学习常常也结束了

原来的问答能回答问题，却接不住下一次学习。三个具体的断点：

留不下

问完就散

游客问答不落库，关掉页面就找不到刚才的解释。

接不上

每次重来

想继续追问，只能重新组织一遍问题，历史无法接上。

看不懂

前置只有一行字

前置知识以名称列表出现，学生知道该补，却不知道从哪里看起。

不是答案不够好，是学习没有留下一条可以回来的路径。

总览

四个功能，
接成一条回路

从“我是谁”开始，到“我下次还能回到哪里”。

01

登录

让系统认出同一个人，后面的记录才有归属。

02

历史

让问题留下上下文，下次可以接着问。

03

语音

让提问不再被打字拦住，先说出来再校对。

04

视频

让前置知识有可看的解释，补上理解的第一块。

四个按钮不是终点；它们把一次问答，变成一条能继续走的路。

01 · 用户登录

先认出你，
再记住你

登录不是加一道门，而是让历史、继续提问和上下文有归属。

游客 不落库

提问 → 回答 → 离开。适合快速试问，但不会留下记录。

学生 Bearer

登录 → 提问 → 保存。下一次打开，仍能回到原来的上下文。

POST /api/auth/login→auth_sessions→Authorization: Bearer
1

提交登录 / 注册

注册用 POST /api/auth/register，登录用 /login；用户名 3–32 位，注册密码 8–128 位。

2

服务端校验并签发令牌

scrypt 校验；失败统一 401。成功写入 auth_sessions，返回 token、expires_at、user。

3

后续请求带 Bearer

/api/auth/me 读取当前用户；401 时前端清空本地令牌并回到登录。

默认 30 天
auth_sessions.expires_at
统一提示
401 INVALID_CREDENTIALS
限流
注册 5 次/小时；登录失败 10 次/15 分钟
可撤销
退出调用 /api/auth/logout

02 · 历史会话

问过的问题，
不必从零开始

一次提问被拆成会话与消息保存；下次打开，仍能沿着原来的上下文继续。

继续 →

POST /api/ask→messages→message_knowledge_points

1

发起并确定会话

POST /api/ask 带 conversation_id；没有则创建 conversations 行，标题取首个问题。

2

先写问题，再写回答

user message 先落库；生成完成后写 assistant message，失败也保留 status=failed。

3

知识点关联与分页读取

message_knowledge_points 存 node_key；列表和消息都用 cursor 游标分页。

登录后才写入历史

03 · 语音识别

把“说出来”，
变成“问出来”

语音只负责把话变成字；发送与否，仍然由学生确认。

01

点麦克风

App 申请 RECORD_AUDIO；H5 检查 HTTPS/localhost 与 MediaRecorder。

02

录音

App mp3/16kHz/30s；H5 优先 MP4/AAC，必要时转 16kHz WAV。

03

上传

POST /api/transcribe，multipart 字段 file，≤5MB；按文件头校验格式。

04

识别

后端转 Data URL，调用 qwen3-asr-flash，stream=false，超时 30s。

05

回填并确认

返回 {text} 追加到输入框；用户校对后点发送，走 /api/ask。

POST /api/transcribe·multipart file ≤ 5MB·qwen3-asr-flash·30s timeout

H5 麦克风需要 HTTPS 或 localhost 音频不落盘，日志不记录内容 ASR 未配置只影响语音入口
边界权限、网络、浏览器支持或 ASR 配置失败时，只提示重试，不影响文本问答。

请求时序

从一句话，
到一张视频卡

把一次提问拆成请求、检索、生成、落库和视频查询五段，每一步都有明确的输入和输出。

前端→ POST /api/ask {question, conversation_id}
后端· link_top → diagnose → build_learning_path → build_prompt
后端· insert_user_message → Qwen 生成 → split_generated_answer
后端· insert_assistant_message + message_knowledge_points
前端← answer + prerequisite_gaps[].id + learning_path.body_id
前端→ GET /api/videos ?node_key=…&limit=2
前端← embed_url → H5 iframe / APK 独立播放页

运行时只读 SQLite·视频查询不访问 B 站·Qwen 只负责生成回答
