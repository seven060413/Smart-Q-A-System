**选题 7　中小学教材知识图谱智能问答系统**

难度：★★★ 提高型（教师评分加 3 分）　　硬件档：B

**1　选题意义**

学生提问时往往缺的不是这道题的答案，而是前置知识。纯文本检索找不到隐含的前置知识点，讲解就会跳跃。这个题目把教材抽取成知识图谱，问答时同时用文本证据和图证据，并回溯前置知识链，先补前置再讲本体。图谱的关系建模和图检索是这个题目的内核，也是当前教育大模型研究的主流做法。

**2　核心功能（包括但不限于）**

（1）图谱构建：从教材中抽取知识点实体与关系（包含、前置、并列）。

（2）实体链接：把用户问句中的概念链接到图谱节点。

（3）双通道检索：文本向量检索加图谱子图检索。

（4）前置知识诊断：识别题目涉及知识点，回溯前置链，判定学生可能的知识缺口。

（5）学习路径生成：按图谱拓扑生成前置、本体、巩固三级练习路径。

（6）溯源输出：答案必须标注出处章节，无证据时明确拒答。

（7）评测：抽样题目自动评测加人工抽检讲解质量。

**3　输入输出测试示例（包括但不限于如下用例）**

（1）输入：学生问\"为什么异分母分数相加要先通分\"。输出：本体知识点\"异分母分数加法\"；前置链检测结果：依赖\"最小公倍数\"与\"等值分数\"，这两项在前置关系中均标记为必需；建议先补前置；答案附出处：人教版五年级下册第
X 单元。

（2）输入：问一个教材外的内容（如高中导数）。输出：拒答，提示\"当前知识库未覆盖该内容\"，并给出最接近的已覆盖知识点。

（3）测试用杀手用例：在图谱中人为制造一条环（A 是 B 的前置，B 又是 A
的前置），系统应报出前置关系存在环，无法生成学习路径，并输出环的完整节点序列。

**4　可能用到的数据**

公开教材知识图谱数据集可用北京大学
K12-KGraph（人教版小初高数理化教材抽取的图谱与配套题库），使用前须确认授权范围，仅作课程研究用途。不要批量爬取教材网站，无官方下载授权。

**5　核心技术**

Python；Neo4j 或 NetworkX 存图；LightRAG 或 GraphRAG
做图结构检索；bge-m3 做向量召回；Qwen 系列模型做生成；FastAPI 加 Vue3
做系统。

**6　硬件与资源需求**

B 档。小向量模型可在 CPU
上跑，生成环节建议用在线接口。若本地部署模型则升为 C 档。

**7　完成难度与主要难点**

（1）知识图谱的抽取质量决定天花板，抽取不准后面全部作废

（2）教材语料的授权问题，不要批量爬取教材网站

（3）图检索与文本检索的结果如何融合，融合规则要有依据

难度过大时的降级方案：直接使用北京大学 K12-KGraph
等公开图谱数据集，不要自己从教材里抽；图谱规模限制在 200
个知识点以内；只做单一学科（如数学），不要贪多。
