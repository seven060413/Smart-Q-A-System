# 02 · 代码与文档清理建议

> 本文回答“哪些模块/脚本/文档可能已经没用了”。
> 原则：**只列证据，不替你删。** 视频功能是活的，不要因为“早期 B 站尝试失败”就整组删除。

---

## 一、先给结论

1. **视频/B 站功能是在用的，不是废弃实验。**
   - `src/api.py` 导入并注册了 `video_api.router`。
   - `src/schema.py` 的迁移 2/3 创建了 `videos`、`knowledge_point_videos`、`video_candidates` 等表。
   - `app/src/pages.json` 注册了 `pages/video/video`；首页和路径页会调用 `/api/videos`。
   - `tests/test_videos.py`、`tests/test_video_import.py` 存在。
   - 真正“没接进主流程”的只有 `src/retrieval.py` 和 `src/fusion.py`，不是整个视频模块。

2. **没有“完全没人引用”的 `src/*.py`。** 每个模块至少被测试或脚本引用；问题在于有些模块只被自己的测试引用（`retrieval.py`、`fusion.py`），属于“测试养着孤儿代码”。

3. **文档问题比代码问题多。** 多份文档描述的是旧阶段状态（HTTPS 未做、双通道已完成、11 张表等），与当前代码不一致；还有两组完全重复的文件。

4. **不要执行批量删除。** 下面标“高置信度”的文件可以清理；标“中/低”的请先确认。
