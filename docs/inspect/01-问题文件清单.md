# 01 · 问题文件清单

> 本文逐个说明问题文件的用途、大小、是否含敏感数据、风险等级和处理建议。
> 风险等级：🔴 极高 / 🟠 高 / 🟡 中 / 🟢 低。

---

## 风险图例

| 标记 | 含义 |
|---|---|
| 🔴 极高 | 含真实用户数据、密码哈希或聊天内容，必须从公开历史移除 |
| 🟠 高 | 含真实标识符/内部信息，或会明显扩大暴露面，建议从历史移除 |
| 🟡 中 | 构建产物、临时部署包、日志、本地配置，不应入库但通常不构成密钥泄露 |
| 🟢 低 | 空文件、误操作产物，清理即可 |

“已推送”指该文件存在于 GitHub 当前分支或历史中；“未跟踪”指只在本地，尚未进入 GitHub。
