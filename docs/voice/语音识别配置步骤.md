# 语音识别（Qwen-ASR）配置步骤

> 目标：让本项目的 `POST /api/transcribe` 能调用阿里云百炼的 `qwen3-asr-flash`，
> 把录音转成文字。
>
> 本文只写步骤和占位符，**不要把自己的真实 API Key 写进本文档或提交到 Git**。

---

## 0. 先弄懂四个东西的关系

| 概念 | 是什么 | 类比 |
| --- | --- | --- |
| 地域 Region | 模型部署在哪个物理区域（北京、新加坡……） | 城市 |
| 业务空间 Workspace | 账号下的资源分区，用于权限和费用隔离 | 公司里的部门 |
| API Key | 调用凭证，创建时属于某个地域 + 某个业务空间 | 某部门的门禁卡 |
| Base URL | 请求入口地址，分“公共入口”和“部门专属入口” | 大楼入口 |

绑定规则（记住这一条就够了）：

- **地域必须一致**：北京地域的 Key 只能配北京地域的地址，跨地域会 401/403。
- **业务空间专属地址只认本空间的 Key**：
  `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
  用别的空间（包括“默认业务空间”）的 Key 会被拒绝。
- **公共地址可以跨业务空间使用**：
  `https://dashscope.aliyuncs.com/compatible-mode/v1`（北京）
  用哪个空间的 Key 都行，前提是该 Key 有权限调用这个模型。

所以你有两条路，**推荐先走方案 A**，最省事。

---

## 方案 A：公共地址 + 你现有的 Key（推荐）

适合：你已经有 `QWEN_API_KEY`，不想再新建 Key。

### 1. 确认地域

打开百炼控制台 API Key 页面：

```text
https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key
```

看页面**右上角的“地域”**，确认是 **华北2（北京）**。如果不是，先切换。

### 2. 复制现有 Key

在 Key 列表里找到你现在用于 `QWEN_API_KEY` 的那把 Key，直接复制。
同一把 Key 可以同时用于文本生成和语音识别，不需要分开。

### 3. 确认模型可用

进入控制台的 **模型广场**，搜索 `qwen3-asr-flash`，打开模型详情：

- 能看到模型、能看到计费说明，通常就说明当前账号/空间可以调用；
- 如果页面提示需要“开通”或同意协议，按提示开通；
- 如果你在**子业务空间**里操作，要确认该空间已被授权这个模型。

### 4. 填入 `.env`

在项目根目录 `.env` 里追加（值自己填，不要提交）：

```ini
ASR_API_KEY=和 QWEN_API_KEY 相同的值
ASR_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
ASR_MODEL=qwen3-asr-flash
```

## 方案 B：业务空间专属地址

适合：你在百炼里专门建了一个业务空间，想用它做隔离或更高吞吐。

### 1. 确认地域和业务空间

- 地域：**华北2（北京）**；
- 业务空间：就是你地址里 `ws-` 后面那一段对应的空间。
  在控制台页面顶部/右上角可以切换或查看当前业务空间。

### 2. 创建“属于这个空间”的 Key

在 API Key 页面点击 **“创建 API Key”**：

- **归属账号**：默认“阿里云账号（主账号）”即可；
- **归属业务空间**：**必须选成你这个 `ws-...` 对应的业务空间**，不能是“默认业务空间”；
- **权限**：选“全部”，或自定义但确保包含 `qwen3-asr-flash`；
- 创建后复制 Key。

### 3. 填入 `.env`

```ini
ASR_API_KEY=第 2 步在这个业务空间里创建的 Key
ASR_BASE_URL=https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
ASR_MODEL=qwen3-asr-flash
```

把 `{WorkspaceId}` 换成你控制台里的实际值（形如 `ws-xxxxxxxx`）。
**注意**：地址只写到 `/compatible-mode/v1` 为止，不要再加 `/chat/completions`，代码里会自己拼。

### 4. 确认模型已授权给这个空间

进入 **模型广场**，或用该空间的 Key 实际调用一次（见下面的验证步骤）。
子业务空间默认只开放已授权的模型，`qwen3-asr-flash` 不可用时要在空间管理里授权。

## 验证

### 1. 重启后端

`.env` 只在进程启动时读取，修改后必须重启：

```powershell
cd D:\IKGR-system-eands
.venv/Scripts/python.exe -m uvicorn src.api:app --host 0.0.0.0 --port 18080
```

### 2. 用一段短音频测试

准备一个 5 秒左右的 `test.mp3`（有说话声），然后：

```powershell
curl.exe -F "file=@D:\test.mp3" http://127.0.0.1:18080/api/transcribe
```

成功：

```json
{"text":"为什么异分母分数相加要先通分"}
```

### 3. 错误对照表

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 401 / 403 | Key 与地域或业务空间不匹配；Key 被禁用；Key 无该模型权限 | 换用同空间 Key，或改用方案 A 的公共地址 |
| 404 / 模型不存在 | 模型名写错；该空间未授权模型；地域选错 | 确认 `ASR_MODEL=qwen3-asr-flash`，在控制台授权模型 |
| 400 `NO_SPEECH` | 录音静音、太短、没说话 | 重录一段清晰普通话 |
| 400 `UNSUPPORTED_FORMAT` | 文件头不是支持的音频格式 | 用 mp3/wav 重新录制 |
| 413 `AUDIO_TOO_LARGE` | 文件超过 5MB | 缩短录音或降低码率 |
| 502 `ASR_UPSTREAM_ERROR` | 百炼拒绝该音频（如 webm/ogg 不被支持）或服务异常 | 看后端日志里的上游状态码，换 mp3 测试 |
| 502 `ASR_NOT_CONFIGURED` | `.env` 缺 `ASR_API_KEY` 或 `ASR_BASE_URL` | 补齐后重启 |
| 504 `ASR_TIMEOUT` | 网络或服务端超时 | 稍后重试，检查服务器到百炼的网络 |

后端日志只记录模型名、状态码和耗时，**不会打印 Key 或录音内容**。

## 安全与常见坑

1. **Key 只放 `.env`**：`.env` 已被 `.gitignore` 忽略；不要写进前端、代码、文档、聊天记录。
2. **Key 前缀**：普通按量计费的 Key 以 `sk-` 开头，配 `compatible-mode/v1` 地址；
   如果控制台给你的 Key 以 `sk-sp-` / `sk-ws-` 开头（套餐类），按控制台指示使用对应地址。
3. **地域不能跨用**：北京地址配北京 Key；新加坡地址配新加坡 Key。
4. **专属地址不要配默认空间的 Key**：这是 401/403 最常见的原因。
5. **`.env` 不要覆盖服务器版本**：服务器上的 Key 以服务器 `/opt/ikgr/.env` 为准。
6. 语音识别与文本生成是两套配置项（`ASR_*` 与 `QWEN_*`），可以填同一个 Key，但不要混用模型名。
7. **前端不接触 ASR 密钥**：H5 与 APK 只调用后端 `POST /api/transcribe`，由后端请求百炼；
   不要在前端代码里直接请求 Qwen/百炼，也不要把 `ASR_API_KEY` 打包进 APK。
8. **前端后端地址**在 [app/src/config.js](../../app/src/config.js) 的 `BASE_URL`：
   默认 `http://127.0.0.1:18080`（本地开发）；手机局域网改用电脑的局域网 IP；
   H5 麦克风要求 HTTPS 或 localhost；APK 会在打包时写死地址，改后需重新打包。
