# 如何查看本项目的网页版（H5）

> 面向**第一次拿到本项目代码**的同学 / 老师：从 GitHub 克隆后，在浏览器里跑起来。
> 全程约 10 分钟，**不需要 HBuilderX**，也不需要安卓手机。

---

## 0. 前置条件

| 软件 | 版本要求 | 下载地址 | 验证命令 |
| --- | --- | --- | --- |
| **Python** | 3.9+（推荐 3.11） | https://www.python.org/downloads/ | `python --version` |
| **Node.js** | 18+（推荐 20/22/24） | https://nodejs.org/ | `node -v` 和 `npm -v` |
| **Git** | 任意较新版本 | https://git-scm.com/ | `git --version` |

> 安装 Python 时勾选 **Add Python to PATH**；安装 Node.js 后**重新打开终端**再验证。

## 1. 克隆代码

```powershell
git clone https://github.com/seven060413/Smart-Q-A-System.git
cd Smart-Q-A-System
```

> 如果仓库设置了私有，需要先登录 GitHub 或用 Personal Access Token。

---

## 2. ⚠️ 下载数据文件（必须，否则后端启动失败）

**这一条最容易漏**：原始数据集体积较大，没有放进 Git 仓库，需要自己下载。

```powershell
# 在项目根目录执行
New-Item -ItemType Directory -Force -Path data\raw | Out-Null
curl.exe -L -o data\raw\math.json "https://huggingface.co/datasets/lhpku20010120/K12-KGraph/resolve/main/K12-KGraph/subject_specific_KG/math.json"
```

**验证**：文件大小约 **2.2 MB**。

```powershell
Get-Item data\raw\math.json | Select-Object Name, Length
```

> 如果 `curl` 无法识别，用浏览器打开上面的链接直接下载，放到 `data\raw\math.json`。

**数据来源与授权**：北京大学 K12-KGraph，CC BY-NC-SA 4.0，仅课程研究用途，详见 [data/README.md](../data/README.md)。

## 3. 创建 Python 虚拟环境并安装依赖

```powershell
# 创建虚拟环境
python -m venv .venv

# 安装依赖（服务端最小依赖，约 1 分钟）
.venv\Scripts\python.exe -m pip install -r requirements-server.txt
```

> **不要装 `requirements.txt`**：它包含 bge-m3 / torch（约 2GB），只有本地构建向量索引时才需要，
> 运行网页版问答用 `requirements-server.txt` 就够。

**macOS / Linux 用户**：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-server.txt
```

---

## 4. 配置 Qwen 密钥

```powershell
Copy-Item .env.example .env
```

用记事本或 VS Code 打开 `.env`，填入你自己的 DashScope 密钥：

```ini
QWEN_API_KEY=sk-你自己的密钥
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen-plus
BGE_MODEL=BAAI/bge-m3
DATA_DIR=data
```

**密钥获取**：https://dashscope.console.aliyun.com/ （注册后有免费额度）

> 没有密钥也能启动并看到界面、看到「拒答」效果，但**正常问答会失败**（生成环节需要 Qwen）。

## 5. 启动后端

```powershell
.venv\Scripts\python.exe -m uvicorn src.api:app --host 0.0.0.0 --port 18080
```

看到下面这行即成功（**这个窗口不要关**）：

```
INFO:     Uvicorn running on http://0.0.0.0:18080
```

**另开一个终端验证**：

```powershell
curl.exe http://127.0.0.1:18080/
```

期望返回：

```json
{"service":"中小学教材知识图谱智能问答系统","docs":"/docs"}
```

> 端口 18080 被占用时，改 `--port 18081`，同时修改前端地址（见第 6 步）。

---

## 6. 修改前端后端地址 + 启动前端

### 6.1 确认地址

打开 `app/src/config.js`：

```js
export const BASE_URL = 'http://114.55.116.162:18080'
```

**如果你在本地跑后端**，改成：

```js
export const BASE_URL = 'http://127.0.0.1:18080'
```

> 仓库里默认指向作者的云服务器；如果你直接用默认值，**不需要自己启动后端**（见文末「方式二」）。

### 6.2 安装前端依赖并启动

```powershell
cd app
npm install
npm run dev:h5
```

终端会打印访问地址，通常是：

```
➜  Local:   http://localhost:5173/
```

## 7. 在浏览器中查看

打开：

```
http://localhost:5173/
```

**建议按 F12 → 点左上角手机图标**，切换到手机尺寸（iPhone / Android），看到的就是 App 的实际布局。

### 验证功能

在输入框输入：

```
为什么异分母分数相加要先通分
```

期望结果：

- 顶部显示知识点「**异分母分数加减法**」；
- 出处显示「**人教版五年级下册·分数的加法和减法**」；
- 三段可折叠：前置知识 / 本体讲解 / 巩固练习；
- 底部「**查看学习路径**」→ 显示「前置 → 本体 → 巩固」三级流程图。

再输入一个库外问题：

```
什么是导数
```

期望：显示红色拒答卡「**当前知识库未覆盖该内容**」，并提示最接近知识点。

## 方式二：不想装后端，直接用现成服务

如果作者的公网服务可用，可以跳过第 3–5 步：

1. 保持 `app/src/config.js` 中的默认地址 `http://114.55.116.162:18080`；
2. 只做第 6.2 步（`cd app && npm install && npm run dev:h5`）；
3. 浏览器打开 `http://localhost:5173/`。

**验证后端是否可用**：

```powershell
curl.exe http://114.55.116.162:18080/
```

有 JSON 返回即可用。

> 注意：该地址是作者的课程演示服务器，可能因流量/关机不可用。长期使用请按第 3–5 步本地部署。

## 只用浏览器看构建产物（不启动开发服务器）

```powershell
cd app
npm run build:h5
```

产物在 `app/dist/build/h5/`，需要用一个 HTTP 服务器打开（**不能直接双击 index.html**）：

```powershell
cd dist/build/h5
python -m http.server 8080
```

浏览器访问 `http://localhost:8080/`。

## 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| `python: 不是命令` | Python 未加入 PATH；重装并勾选 Add to PATH |
| `npm: 不是命令` | Node.js 未加入 PATH；**安装后要新开终端** |
| 后端启动报 `FileNotFoundError: data/raw/math.json` | **第 2 步没做**，数据文件没下载 |
| 后端启动报 `ModuleNotFoundError` | 依赖没装进 venv，确认用的是 `.venv\Scripts\python.exe -m pip` |
| 网页打开是空白 | F12 看 Console 报错；确认 `npm run dev:h5` 的窗口没有报错 |
| 提问后提示「网络请求失败」 | 后端没启动 / `config.js` 地址不对 / 端口不一致 |
| 提问后返回 500 | `.env` 里的 Qwen 密钥无效或未配置 |
| `npm.ps1 无法加载` | PowerShell 执行策略限制，管理员执行 `Set-ExecutionPolicy -Scope LocalMachine RemoteSigned` |
| 端口 18080 被占用 | 换端口启动，同时改 `app/src/config.js` |

```

├── src/                 # 后端（FastAPI）
├── app/                 # 前端（uni-app + Vue3）
```
