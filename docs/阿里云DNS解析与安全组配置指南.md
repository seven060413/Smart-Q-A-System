# 🌐 阿里云 DNS 解析 & 安全组配置 - 详细操作指南

> **适用场景**：将域名 `seventeen17.com.cn` 指向服务器 `114.55.116.162`，并放行 HTTP/HTTPS 端口  
> **操作时间**：约 10-15 分钟  
> **难度**：⭐⭐（跟着步骤点即可，无需技术背景）

---

## 📋 操作概览

本次需要完成两件事：

| 序号 | 操作 | 目的 |
|------|------|------|
| ① | **添加 DNS 解析记录** | 让 `seventeen17.com.cn` 指向你的服务器 IP |
| ② | **配置安全组规则** | 允许外部访问服务器的 80/443 端口 |

**建议顺序**：先做 ①（DNS），再做 ②（安全组），或者反过来都行，两者独立。

---

## 🔍 第一部分：DNS 解析配置（让域名指向服务器）

### 步骤 1：登录阿里云控制台

1. 打开浏览器，访问：**https://dc.console.aliyun.com/**
2. 使用你的阿里云账号登录（手机号/邮箱 + 密码）
3. 如果提示选择"账号"或"角色"，选择你的**主账号**

### 步骤 2：进入域名解析列表

**方法 A（推荐）**：
1. 在页面顶部搜索框输入 **"域名解析"**
2. 点击搜索结果中的 **"云解析 DNS"**

**方法 B（手动导航）**：
1. 在页面左上角，点击 **☰ 三横线菜单**（产品与服务）
2. 找到 **"域名与网站（或 网络域名"）** 分类
3. 点击 **"域名解析"** → **"解析设置"**

### 步骤 3：找到你的域名

在域名列表中找到 **`seventeen17.com.cn`**，点击右侧的 **"解析设置"** 按钮（蓝色文字链接）

> 💡 **如果看不到这个域名**：
> - 可能域名不在当前账号下，检查是否登录了正确的阿里云账号
> - 或者联系购买域名的人确认

### 步骤 4：添加 A 记录（@ 主域名）

进入解析设置页面后：

1. 点击页面上方的 **"+ 添加记录"** 按钮（通常在左上角，蓝色按钮）
2. 在弹出的表单中填写：

   | 字段 | 填写内容 | 说明 |
   |------|----------|------|
   | **记录类型** | `A` | 选择"A"（表示 IPv4 地址） |
   | **主机记录** | `@` | 代表主域名 `seventeen17.com.cn` |
   | **解析线路** | `默认` | 不用改 |
   | **记录值** | `114.55.116.162` | 你的服务器公网 IP |
   | **TTL** | `10 分钟` | 可选，默认即可 |

3. 点击 **"确定"** 保存

> ⚠️ **注意**：主机记录填 `@` 符号（Shift+2），不是文字 "at"

### 步骤 5：添加 A 记录（www 子域名）

重复步骤 4，再添加一条记录：

1. 再次点击 **"+ 添加记录"**
2. 填写：

   | 字段 | 填写内容 |
   |------|----------|
   | **记录类型** | `A` |
   | **主机记录** | `www` |
   | **解析线路** | `默认` |
   | **记录值** | `114.55.116.162` |
   | **TTL** | `10 分钟` |

3. 点击 **"确定"** 保存

### 步骤 6：验证 DNS 配置成功

添加完成后，你应该在记录列表中看到两条记录：

```
@       A    114.55.116.162    正常
www     A    114.55.116.162    正常
```

**验证方法**（等 1-5 分钟后）：

打开电脑的 **命令提示符（CMD）** 或 **PowerShell**，输入：

```bash
nslookup seventeen17.com.cn
```

如果看到类似这样的输出，说明 DNS 配置成功：
```
名称:    seventeen17.com.cn
Address: 114.55.116.162
```

> ⏳ **DNS 生效时间**：通常 1-10 分钟，最长可能需要 48 小时（国内一般很快）

## 🔒 第二部分：安全组配置（放行 80/443 端口）

### 什么是安全组？

**安全组** = 阿里云服务器的"防火墙规则"
- 它决定哪些端口可以从外部访问
- 默认只开放了 22（SSH）和 3389（远程桌面）等少数端口
- **必须手动添加规则才能开放 80（HTTP）和 443（HTTPS）**

### 步骤 1：进入 ECS 控制台

1. 打开：**https://ecs.console.aliyun.com/**
2. 或者在阿里云首页搜索 **"ECS"** / **"云服务器 ECS"**

### 步骤 2：找到你的服务器实例

在实例列表中找到 IP 为 **`114.55.116.162`** 的服务器：

- 查看 **"实例名称"** 或 **"公网 IP"** 列
- 如果实例很多，可以用右上角的搜索框搜索 IP 地址

### 步骤 3：进入安全组配置

**方法 A（从实例列表进入，推荐）**：

1. 找到你的服务器实例所在行
2. 点击最右侧的 **"更多"** 按钮（三个点 ⋯）
3. 在下拉菜单中选择 **"安全组配置"**

**方法 B（通过左侧菜单）**：

1. 在页面左侧导航栏找到 **"网络与安全"**
2. 点击 **"安全组"**
3. 找到与你的服务器关联的安全组（通常叫"default"或你自定义的名字）
4. 点击 **"配置规则"**

### 步骤 4：添加入方向规则（入方向 = 外部访问服务器）

进入安全组规则页面后：

1. 点击 **"入方向"** 标签页（通常默认就是这个）
2. 点击 **"手动添加"** 或 **"+ 添加规则"** 按钮（页面右上角或中部）

#### 规则 1：放行 HTTP（80 端口）

在弹出的表单中填写：

| 字段 | 填写内容 | 说明 |
|------|----------|------|
| **授权策略** | `允许` | 必须选"允许" |
| **优先级** | `1` | 数字越小优先级越高，填 1 即可 |
| **协议类型** | `TCP` | 自定义 TCP |
| **端口范围** | `80/80` | 只开放 80 端口 |
| **授权对象** | `0.0.0.0/0` | 表示允许所有 IP 访问 |
| **描述** | `HTTP - IKGR前端` | 可选，方便记忆 |

> 💡 **快速填写技巧**：
> - 协议类型选 **"自定义 TCP"**
> - 端口范围直接输入 **`80/80`**
> - 授权对象输入 **`0.0.0.0/0`**

#### 规则 2：放行 HTTPS（443 端口）

点击 **"+" 继续添加规则**，填写第二条：

| 字段 | 填写内容 |
|------|----------|
| **授权策略** | `允许` |
| **优先级** | `1` |
| **协议类型** | `TCP`（自定义 TCP） |
| **端口范围** | `443/443` |
| **授权对象** | `0.0.0.0/0` |
| **描述** | `HTTPS - IKGR前端SSL` |

### 步骤 5：保存规则

1. 填写完两条规则后，点击页面底部的 **"确定"** 或 **"保存"** 按钮
2. 系统会提示"规则更新成功"或类似信息

### 步骤 6：验证安全组配置

保存后，你应该在入方向规则列表中看到新添加的两条规则：

```
允许  TCP  80/80     0.0.0.0/0   HTTP - IKGR前端
允许  TCP  443/443   0.0.0.0/0   HTTPS - IKGR前端SSL
```

**立即生效测试**（在本地 PowerShell 执行）：

```bash
# 测试 80 端口是否通
Test-NetConnection -ComputerName 114.55.116.162 -Port 80

# 测试 443 端口是否通
Test-NetConnection -ComputerName 114.55.116.162 -Port 443
```

如果看到 `TcpTestSucceeded : True`，说明端口已开放 ✅

## ❓ 常见问题

### Q1：找不到"域名解析"入口？
**A**：确保你用的是购买域名的那个阿里云账号登录。域名可能在子账号下。

### Q2：添加记录时提示"记录已存在"？
**A**：说明之前已经配置过了。点击"编辑"修改现有的记录值即可。

### Q3：安全组里已经有 80/443 规则了？
**A**：太好了！检查一下授权对象是否是 `0.0.0.0/0`，如果是就不用重复添加。

### Q4：DNS 配置好后还是无法访问？
**A**：
1. 等 5-10 分钟让 DNS 生效
2. 检查安全组是否真的放行了端口
3. 检查服务器上 Nginx 是否已安装并启动
4. 用 `telnet 114.55.116.162 80` 测试端口连通性

### Q5：`0.0.0.0/0` 安全吗？会不会被攻击？
**A**：
- 对于公开的 Web 服务（HTTP/HTTPS），这是标准做法
- 80/443 端口本来就是给公网访问的
- 真正敏感的是后端 18080 端口，部署完成后可以限制为仅 `127.0.0.1` 访问
- 后续还可以加 WAF 防火墙、CDN 等增强安全性

### Q6：我想用 `math.seventeen17.com.cn` 这样的子域名？
**A**：
1. DNS 添加 A 记录：主机记录填 `math`，记录值填 `114.55.116.162`
2. Nginx 的 `server_name` 加上 `math.seventeen17.com.cn`
3. Certbot 申请证书时加上 `-d math.seventeen17.com.cn`
