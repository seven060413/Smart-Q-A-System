# 实体链接与双通道检索设计

## 1. 实体链接（src/linking.py）

把用户问句中的概念映射到图谱知识点节点。

方法：对每个知识点节点，计算「节点名 + 别名」与问句的相似度：

```
score = 0.7 * dice + 0.3 * coverage
```

- **Dice 系数（字符二元组）**：衡量共现片段，能区分「异分母分数加减法」与「通分」这种包含/局部关系——「通分」虽字全命中，但只有 2 个字、片段太短，Dice 很低；
- **字符覆盖度**：节点名中有多少字出现在问句中，兜底处理片段不连续但字面相关的场景。

两个信号都归一化到 [0,1] 再加权，量纲一致。后续可接入 bge-m3 句向量做语义增强。

## 2. 文本通道（src/retrieval.py）

- 向量化文本 = 知识点名称 + 定义（Concept 取 `definition`，Skill 取 `description`）；
- 用 bge-m3（FlagEmbedding，本地 CPU）生成句向量；
- 查询时按余弦相似度召回 Top-K。

## 3. 图谱通道（src/graph.py + src/fusion.py）

- **前置链回溯**：`indirect_prerequisites`（即 `nx.ancestors`，含间接前置）；
- **相邻子图查询**：`neighbor_subgraph`（radius 跳诱导子图）；
- **连通性判定**：`has_path` / `weakly_connected_components`；
- **环检测**：`find_cycles`（输出完整闭环序列，对应杀手用例）。

## 4. 融合规则（src/fusion.py）

> 教师要求「融合规则要有依据」，本规则依据如下。

```
final = 0.7 * text_score + 0.3 * graph_score
```

- `text_score`：余弦相似度，天然归一化到 [0,1]；
- `graph_score`：节点是否落在锚点前置链或相邻子图内（命中 1.0，否则 0）。

**权重依据**：

1. 语义相关性是问答的**第一证据**——用户问的是「内容」，故文本通道权重更高（0.7）；
2. 图谱结构是**第二证据**——前置/邻近关系用于补全学生缺的前置知识，但不改变主答案，故权重较低（0.3）；
3. 两个通道分数必须归一化到**同一量纲 [0,1]** 才能直接加权，否则量纲差异会扭曲权重含义。
