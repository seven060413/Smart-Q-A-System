# 后端部署与更新手册

> 适用：FastAPI 后端部署到阿里云 ECS，以及后续修改 `src/`、`scripts/`、依赖或图谱数据后的发布。
> 目标：可重复、可验证、可回滚；不覆盖服务器 `.env`，不误删用户数据库。
> 本文不记录密码、私钥或真实密钥；SSH 密码由你在终端自行输入。

## 0. 参数与架构

| 参数 | 当前值 |
|---|---|
| 服务器公网 IP | `114.55.116.162`（阿里云 ECS） |
| 域名 | `seventeen17.com.cn`，HTTPS 见 [HTTPS部署指南.md](HTTPS部署指南.md) |
| 部署目录 / 服务名 | `/opt/ikgr` / `ikgr` |
| 后端端口 | `18080` |
| 数据库 | `data/app/ikgr.db`（SQLite，本地/服务器各一份，不入 Git） |
| 前端目录 | `/opt/ikgr/frontend`（Nginx 静态文件） |

调试用 `0.0.0.0:18080` + 放行 18080；生产用 `127.0.0.1:18080` + 只开 80/443，由 Nginx 反代。

## 1. 首次部署（新服务器）

### 1.1 本地打包

只打包后端代码和依赖；**绝不打包 `.env`、`data/app/`、`.venv`、`node_modules`**。

```powershell
cd D:\IKGR-system-eands
Remove-Item D:\ikgr-deploy -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Path D:\ikgr-deploy | Out-Null
Copy-Item src -Destination D:\ikgr-deploy -Recurse
Copy-Item scripts -Destination D:\ikgr-deploy -Recurse
Copy-Item requirements-server.txt -Destination D:\ikgr-deploy
# 仅图谱 JSON 变化时才复制 data/（原始数据需另行下载）
Compress-Archive -Path D:\ikgr-deploy\* -DestinationPath D:\ikgr-backend.zip -Force
```

打包后检查：解压 zip，确认包内没有 `.env` 和 `*.db`；有则不要上传。

### 1.2 上传与安装环境

```powershell
scp D:\ikgr-backend.zip root@114.55.116.162:/root/
```

> 注意：`scp` 在本地 PowerShell 执行；`ssh` 之后的命令在服务器 bash 执行，不要混用。

```bash
ssh root@114.55.116.162
cd /root
mkdir -p /opt/ikgr
unzip -o ikgr-backend.zip -d /opt/ikgr
cd /opt/ikgr
# Ubuntu / Debian
apt update && apt install -y python3 python3-venv python3-pip unzip
# CentOS / Alibaba Cloud Linux：dnf install -y python3 python3-pip unzip
python3 -m venv .venv
.venv/bin/pip install -r requirements-server.txt
```

> 服务器不需要 `requirements.txt` 中的 `FlagEmbedding`/`torch`（约 2.5GB），用 `requirements-server.txt`。

### 1.3 试启动与安全组

```bash
cd /opt/ikgr
.venv/bin/uvicorn src.api:app --host 0.0.0.0 --port 18080
```

本地另开窗口验证 `curl.exe http://114.55.116.162:18080/`，期望：

```json
{"service":"中小学教材知识图谱智能问答系统","docs":"/docs"}
```

超时通常是安全组未放行。阿里云控制台 → ECS → 实例 → 安全组 → 入方向：

| 协议 | 端口 | 授权对象 | 说明 |
|---|---|---|---|
| TCP | `18080/18080` | `0.0.0.0/0`（仅调试） | IKGR 后端 |

> 配置 HTTPS 后把 18080 收紧为仅本机；系统防火墙也放行 18080。

### 1.4 systemd 常驻

```bash
cat > /etc/systemd/system/ikgr.service << 'EOF'
[Unit]
Description=IKGR Math QA API
After=network.target
[Service]
Type=simple
User=root
WorkingDirectory=/opt/ikgr
# 未配 Nginx 时临时改成 --host 0.0.0.0 完成 HTTP 联调
ExecStart=/opt/ikgr/.venv/bin/uvicorn src.api:app --host 127.0.0.1 --port 18080
Restart=always
RestartSec=3
[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload
systemctl enable --now ikgr
systemctl status ikgr --no-pager
```

### 1.5 前端地址

`app/src/config.js` 的 `BASE_URL` 设为 `https://seventeen17.com.cn`（本地调试可改
`http://127.0.0.1:18080`）。H5 构建/部署见 [HTTPS部署指南.md](HTTPS部署指南.md)；
APK 地址编译期写死，改后必须重新云打包。

## 2. 日常更新（已有服务器）

### 2.1 本地检查与打包

```powershell
cd D:\IKGR-system-eands
.venv\Scripts\python.exe -m pytest tests/ -q   # 当前基线：127 passed, 1 skipped
```

按 1.1 打包，排除 `.env`、`data/app/ikgr.db`、`.venv`、`node_modules`。

### 2.2 上传、备份、替换

```powershell
scp D:\ikgr-backend.zip root@114.55.116.162:/root/
```

```bash

cp /root/ikgr-deploy/requirements-server.txt /opt/ikgr/
ls -la /opt/ikgr/.env /opt/ikgr/data/app/ikgr.db
```

### 2.3 依赖与迁移

```bash
cd /opt/ikgr
.venv/bin/pip install -r requirements-server.txt
.venv/bin/python scripts/migrate.py status
.venv/bin/python scripts/migrate.py
```

迁移版本化，重复执行会跳过已应用版本；当前 schema 含附件、PDF、头像、学情诊断题库/会话等 v4–v9。
失败时不要启动服务，按第 4 节回滚。迁移前会自动生成快照。

学情诊断首次部署或题库更新时，确认服务器上已有
`data/processed/pansgo_math_k12.json`、`pansgo_math_k12_questions.json`、
`pansgo_math_k12_catalog.json`，然后执行：

```bash
cd /opt/ikgr
.venv/bin/python scripts/seed_pansgo_questions.py
```

题库写入是幂等的；重复执行只会更新同 id 的题目。

### 2.4 图谱数据（仅 JSON 变化时）

```bash
cd /opt/ikgr
.venv/bin/python scripts/import_graph.py --json data/raw/math.json --scope subject_full
.venv/bin/python scripts/import_graph.py \
  --json data/processed/math_5b_knowledge_graph.json --scope book --book-id math_5b_rjb
```

内容变化时脚本会要求 `--force`；确认要覆盖再加。原始 JSON 不删除、不覆盖。

### 2.5 视频数据（仅首次/空库）

```bash
cd /opt/ikgr
```

离线写入 6 条已审核视频，不需要 Chrome 或访问 B 站；已有正式数据则跳过。

### 2.6 启动与验证

```bash
systemctl start ikgr
systemctl status ikgr --no-pager
journalctl -u ikgr -n 50 --no-pager
curl -sS http://127.0.0.1:18080/
curl -sS -o /dev/null -w "%{http_code}\n" \
  -X POST http://127.0.0.1:18080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"probe_check","password":"short"}'
curl -sS "http://127.0.0.1:18080/api/videos?node_key=math_5b_rjb_cpt18&limit=1"
```

- 根路径返回 JSON：服务正常；注册探针 `422`：新代码生效；`404`：还是旧代码；
  视频接口 `items`：正常；`[]`：该知识点暂无视频。
- 手机局域网/APK 排查见 [真机调试与APK打包指南](../dev/真机调试与APK打包指南.md) 第 4 节。

## 3. 环境变量（服务器 `/opt/ikgr/.env`）

### 3.1 语音识别（ASR）

```ini
ASR_API_KEY=sk-你的语音识别密钥
ASR_BASE_URL=https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
ASR_MODEL=qwen3-asr-flash
```

- Key 与地域/业务空间必须匹配；也可用公共地址 `https://dashscope.aliyuncs.com/compatible-mode/v1`。
- 未配置时 `/api/transcribe` 返回 502「语音识别服务未配置」，不影响其他功能；
- 改 `.env` 后必须 `systemctl restart ikgr`。

### 3.2 问答匹配范围

`.env` 可设 `QA_MATCH_SCOPE=full`（全量数学，默认）或 `book_5b`（仅五年级下册）；
可选 `QA_LINK_THRESHOLD=0.35`。启动日志打印 `qa match scope=full candidates=1898`。

## 4. 回滚

### 4.1 只回滚代码

```bash
systemctl stop ikgr
cd /opt/ikgr
rm -rf src scripts
tar xzf /root/ikgr_code_backup_<时间戳>.tgz -C /opt/ikgr
systemctl start ikgr
systemctl status ikgr --no-pager
```

### 4.2 代码 + 数据库一起回滚

```bash
systemctl stop ikgr
cd /opt/ikgr
rm -rf src scripts
tar xzf /root/ikgr_code_backup_<时间戳>.tgz -C /opt/ikgr
cp data/app/backups/ikgr_before_deploy_<时间戳>.db data/app/ikgr.db
rm -f data/app/ikgr.db-wal data/app/ikgr.db-shm
systemctl start ikgr
curl -sS http://127.0.0.1:18080/
```

> 回滚数据库会丢失部署后的新用户/新会话，只在确认是迁移/导入导致故障时使用。

## 5. 安全边界

- `.env` 不进 Git/压缩包；服务器权限建议 `chmod 600`。
- `data/app/ikgr.db`、备份和聊天内容属敏感数据，不提交、不发公开网盘。
- 生产必须 HTTPS；Nginx 后 18080 只监听 `127.0.0.1`，安全组只开 80/443。
