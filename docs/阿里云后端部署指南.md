# 后端部署到阿里云服务器

> **服务器信息**
> - 公网 IP：`114.55.116.162`
> - 登录用户：`root`
> - 部署目录：`/opt/ikgr`
> - 服务端口：`18080`
>
> 目标：把 FastAPI 后端部署到公网，手机在任何网络（4G/其他 Wi-Fi）下都能访问。

---

## ⚠️ 先分清两个窗口（最容易出错的地方）

| 窗口 | 提示符长什么样 | 在这里做什么 |
| --- | --- | --- |
| **你的电脑** | `PS C:\...>` 或 `PS D:\IKGR-system-eands>` | 上传文件（scp）、修改前端配置 |
| **阿里云服务器** | `root@iZbp1grf7swkppcebp55c5Z:~#` | 安装环境、启动服务 |

**两个窗口的命令不能混用**：
- 在服务器里执行 `cd D:\IKGR-system-eands` → 报 `No such file or directory`（Windows 路径 Linux 不认）；
- 在电脑上执行 `cd /opt/ikgr` → 报错（Linux 路径 Windows 不认）。

## 0. 准备：部署压缩包

后端已打包为 **`D:\ikgr-backend.zip`**，包含：

```
src/                                        # 后端源码
data/raw/math.json                          # 图谱原始数据 2.2MB
data/processed/math_5b_knowledge_graph.json # 五年级下册子图
requirements-server.txt                     # 服务端依赖（不装 torch）
.env                                        # Qwen 密钥配置
```

**代码改动后需要重新打包**（在【你的电脑】项目根目录执行）：

```powershell
cd D:\IKGR-system-eands
# 删除旧包
Remove-Item D:\ikgr-backend.zip -ErrorAction SilentlyContinue

# 重新打包（排除虚拟环境、缓存、前端）
Compress-Archive -Path src, data\raw\math.json, data\processed\math_5b_knowledge_graph.json, requirements-server.txt, .env -DestinationPath D:\ikgr-backend.zip -Force
```

> 说明：服务端**不需要** `FlagEmbedding` / `torch`（约 2.5GB），那是本地构建向量索引才用的，所以用 `requirements-server.txt` 而不是 `requirements.txt`。

## 1. 上传（在【你的电脑】执行）

**新开一个 PowerShell 窗口**，执行：

```powershell
scp D:\ikgr-backend.zip root@114.55.116.162:/root/
```

- 首次连接会问 `Are you sure you want to continue connecting?` → 输入 `yes` 回车；
- 然后输入服务器密码（输入时不显示字符，正常）。

> 如果提示 `ssh/scp 不是命令`：说明 OpenSSH 不在 PATH 里。
> 修复：把 `C:\Windows\System32\OpenSSH\` 加入用户环境变量 Path，然后**新开窗口**。

## 2. 解压（在【服务器】执行）

登录服务器（如果还没登录）：

```powershell
ssh root@114.55.116.162
```

登录后在 `root@iZbp...:~#` 窗口执行：

```bash
cd /root
mkdir -p /opt/ikgr
unzip -o ikgr-backend.zip -d /opt/ikgr
ls -la /opt/ikgr
```

应看到：`src  data  requirements-server.txt  .env`

若提示 `unzip: command not found`：

```bash
# Ubuntu / Debian
apt install -y unzip
# CentOS / Alibaba Cloud Linux
dnf install -y unzip
```

## 4. 安装依赖并试启动（在【服务器】执行）


```powershell

```

期望返回：

```json
{"service":"中小学教材知识图谱智能问答系统","docs":"/docs"}
```

- ❌ 超时 → 先做第 5 步放行安全组。

## 5. 阿里云安全组放行 18080（必做）

阿里云默认只放行 22/3389，**不放行其他端口**。这是「本地能通、外网超时」的首要原因。

1. 阿里云控制台 → **云服务器 ECS** → 实例；
2. 点进实例 → **安全组** → 点安全组 ID；
3. **入方向** → **手动添加**：

   | 字段 | 填写 |
   | --- | --- |
   | 授权策略 | 允许 |
   | 优先级 | 1 |
   | 协议类型 | 自定义 TCP |
   | **端口范围** | **18080/18080** |
   | 授权对象 | **0.0.0.0/0** |
   | 描述 | IKGR 后端 |

4. 保存（通常几秒内生效）。

**若服务器启用了系统防火墙**，也要放行：

```bash
# firewalld（CentOS / Alibaba Cloud Linux）
firewall-cmd --permanent --add-port=18080/tcp && firewall-cmd --reload

# ufw（Ubuntu）
ufw allow 18080
```

## 6. 配置后台常驻（在【服务器】执行）

用 systemd 托管，实现后台运行 + 开机自启 + 崩溃自动重启。

```bash
cat > /etc/systemd/system/ikgr.service << 'EOF'
[Unit]
Description=IKGR Math QA API
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/ikgr
ExecStart=/opt/ikgr/.venv/bin/uvicorn src.api:app --host 0.0.0.0 --port 18080
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now ikgr
systemctl status ikgr
```

看到 `active (running)` 即成功（按 `q` 退出状态页）。

**常用命令**：

```bash
systemctl restart ikgr      # 改代码后重启
systemctl stop ikgr         # 停止
journalctl -u ikgr -f       # 实时看日志
```

> 如果你的登录用户不是 root，把 service 文件里的 `User=root` 改成实际用户。

## 7. 修改前端地址并重新打包（在【你的电脑】）

编辑 `app/src/config.js`：

```js
export const BASE_URL = 'http://114.55.116.162:18080'
```

**打包前必须验证公网可达**：

1. 手机关掉 Wi-Fi，**用移动数据**；
2. 手机浏览器打开 `http://114.55.116.162:18080/`；
3. 能看到 JSON → 说明公网通，可以打包。

然后在 HBuilderX：**发行 → 原生 App-云打包** → 重新生成 APK。

> ⚠️ 地址是**编译时写死**进 APK 的，改完必须重新打包，旧 APK 不会自动更新。

## 9. 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| `ssh/scp 不是命令` | OpenSSH 不在 PATH：把 `C:\Windows\System32\OpenSSH\` 加入 Path，新开窗口 |
| `Could not resolve hostname 47.xx.xx.xx` | 文档里的**占位符**没替换，实际 IP 是 `114.55.116.162` |
| `cd: D:IKGR-system-eands: No such file` | 在**服务器**里执行了 Windows 命令，回到你电脑的 PowerShell |
| `cd: /opt/ikgr: No such file` | 压缩包还没上传/解压，先做第 1、2 步 |
| `unzip: command not found` | `apt install -y unzip` 或 `dnf install -y unzip` |
| 本地 curl 通、外网超时 | **安全组没放行 18080**（最常见），或系统防火墙未放行 |
| `ModuleNotFoundError` | 依赖没装进 venv，确认用的是 `.venv/bin/pip` |
| 服务启动后自动退出 | `journalctl -u ikgr -n 50` 看日志，多半是数据文件路径不对 |
| Qwen 调用 401 | 服务器上 `cat /opt/ikgr/.env` 检查 `QWEN_API_KEY` |
| 改了代码没生效 | `systemctl restart ikgr` |
| 手机 App 还是旧地址 | APK 未重新打包，改 `config.js` 后必须重新云打包 |

## 附：部署架构

```
手机 App（任意网络，含 4G）
    │  HTTP  →  http://114.55.116.162:18080/api/ask
    ▼
阿里云安全组（放行 18080）
    ▼
systemd 托管的 uvicorn（FastAPI）
    ├─ NetworkX 知识图谱（/opt/ikgr/data）
    └─ Qwen 在线接口（DashScope，由服务器发起）
```

## 附：与本地部署的区别

| 项 | 本地（局域网演示） | 阿里云 |
| --- | --- | --- |
| 地址 | `http://192.168.156.137:18080`（热点重连会变） | `http://114.55.116.162:18080`（固定） |
| 启动方式 | 手动敲 uvicorn | systemd 自启 |
| 网络要求 | 手机与电脑同一 Wi-Fi | 任意网络（4G 也可） |
| 防火墙 | Windows 防火墙放行 | 阿里云安全组 + 系统防火墙 |
